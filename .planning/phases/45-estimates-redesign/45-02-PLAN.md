Replace the entire component body with NumericFormat. The new implementation:

```typescript
import { NumericFormat } from "react-number-format";
import { Input } from "@/components/ui/input";
import { cn } from "@/lib/utils";

export function CurrencyInput({
  value,
  onChange,
  onBlur,
  onKeyDown,
  className,
  disabled,
  id,
}: CurrencyInputProps) {
  return (
    <NumericFormat
      id={id}
      value={value === 0 ? "" : value}
      prefix="$"
      thousandSeparator
      decimalScale={2}
      fixedDecimalScale={false}
      allowNegative
      customInput={Input}
      className={cn(className)}
      disabled={disabled}
      onBlur={onBlur}
      onKeyDown={onKeyDown}
      onValueChange={(values) => {
        onChange(values.floatValue ?? 0);
      }}
    />
  );
}
```

Key implementation notes:
- `value === 0 ? "" : value` — CONTEXT decision: empty field shows blank, not "$0.00". When value is 0 (unset), pass empty string so NumericFormat shows no content. The user sees blank; $ appears as they type.
- `fixedDecimalScale={false}` — do NOT use `fixedDecimalScale: true` here because it would show "$0.00" on an otherwise blank field. With `fixedDecimalScale=false`, typing "1234" shows "$1,234" and typing "1234.5" shows "$1,234.5" until blur. Consistent with standard financial input UX. (Note: if fixedDecimalScale=true is preferred per style, switch to it — but then handle the blank display differently.)
- `onKeyDown={onKeyDown}` — passes through to the underlying `<Input>` via `customInput`. NumericFormat spreads extra props to customInput. This satisfies the draft-row Enter/Escape keyboard handling in budget-line-item-table and sov-editor.
- `allowNegative` — keeps parity with current implementation (budget adjustments can be negative).
- Remove all old imports: `useState`, `useRef`, `parseCurrencyInput` — none are used.

IMPORTANT: Do NOT remove `parseCurrencyInput` from `lib/utils/format.ts`. It may be imported elsewhere. Only remove the import from `currency-input.tsx` if it was imported there.
