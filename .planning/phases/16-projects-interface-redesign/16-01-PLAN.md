  <files>

  <action>
1. Install the `slug` npm package in the api workspace: `npm install slug` from monorepo root with `--workspace=apps/api`. Also install types if available: `npm install -D @types/slug --workspace=apps/api`.

2. In `apps/api/src/db/schema/tenant.ts`, add a `slug` TEXT column to the projects table definition, after the `jobNumber` field:
   ```
   slug: text("slug"),  // URL-safe slug: {jobnumber}-{projectname}
   ```
   The column is nullable initially so the migration can backfill. After migration it will effectively always be populated.

3. Create `apps/api/src/utils/slug.ts`:
   - Import `slug` from the slug package
   - Export `function generateProjectSlug(jobNumber: string | null, projectName: string): string` that:
     - Joins jobNumber (if present) and projectName with a hyphen
     - Passes through `slug()` with `{ lower: true }`
     - Returns the result
   - Export `async function generateUniqueProjectSlug(jobNumber: string | null, projectName: string, tenantDb: any, tenantSchema: any, excludeProjectId?: string): Promise<string>` that:
     - Calls `generateProjectSlug` for the base slug
     - Queries `tenantSchema.projects` for existing rows with that slug (excluding `excludeProjectId` if provided)
     - If no collision, returns the base slug
     - If collision, appends `-1`, `-2`, etc. until unique
     - Uses `eq` from drizzle-orm for the query

4. Create `apps/api/src/db/migrations/add-project-slug.ts`:
   - Follow the established migration pattern (see Phase 13-09 decision): dotenv config, pool.query, active tenant iteration
   - For each tenant schema:
     a. ALTER TABLE {schema}.projects ADD COLUMN IF NOT EXISTS slug TEXT
     b. SELECT all projects (id, job_number, name) where slug IS NULL
     c. For each project, generate slug using the slug npm package directly (not importing the util to keep migration self-contained)
     d. UPDATE {schema}.projects SET slug = $slug WHERE id = $id
     e. After backfill, CREATE UNIQUE INDEX IF NOT EXISTS idx_projects_slug ON {schema}.projects(slug) WHERE slug IS NOT NULL
   - Run with: `cd apps/api && npx tsx src/db/migrations/add-project-slug.ts`
  </action>
  <verify>
Run `cd apps/api && npx tsx src/db/migrations/add-project-slug.ts` successfully. Verify with a quick SQL check that existing projects have slugs populated and the unique index exists.
  </verify>
  <done>
Projects table has slug column with unique partial index. All existing projects have slug values. Slug utility module exports generateProjectSlug and generateUniqueProjectSlug.
  </done>
