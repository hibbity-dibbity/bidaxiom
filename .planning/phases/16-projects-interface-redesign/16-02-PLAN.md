1. Create `apps/web/app/(dashboard)/projects/components/columns.tsx`:
   - Define column definitions for TanStack Table using `createColumnHelper` or `ColumnDef[]`
   - Columns:
     a. **Job #** (`jobNumber`): width ~100px, monospace font, sortable. If null show "--"
     b. **Project Name** (`name`): width ~300px, render as clickable link to `/projects/{slug}`. Import `slug` package to compute slug from jobNumber + name on the fly for links (until slug comes from API). Bold text.
     c. **Customer** (`customerName`): width ~200px, plain text, show "--" if null
     d. **Status** (`status`): width ~120px, render as Badge with color mapping (same statusColors pattern as current page: green for active, yellow for on_hold, blue for completed, gray for archived). Capitalize and replace underscores.
     e. **Start Date** (`startDate`): width ~120px, formatted as locale date string, show "--" if null
   - Export `columns` array
   - Use Procore-style compact density: `text-sm` for all cells, tight padding

2. Create `apps/web/app/(dashboard)/projects/components/projects-table.tsx`:
   - Accept props: `data: Project[]`, `isLoading: boolean`, `total: number`, `page: number`, `onPageChange: (page: number) => void`, `pageSize: number`
   - Use `useReactTable` with `getCoreRowModel()` and `getSortedRowModel()` (sorting is client-side within the page, filtering is server-side)
   - Wrap data in `React.useMemo` to prevent infinite re-renders (per research pitfall #3)
   - Render using shadcn/ui Table components (Table, TableHeader, TableRow, TableHead, TableBody, TableCell)
   - Add sort indicators (chevron up/down) on sortable column headers
   - Add compact row styling: `py-2` padding on cells, `text-sm` font size, hover state `hover:bg-muted/50`
   - Loading state: Show Skeleton rows (5 rows matching column count)
   - Empty state: Show "No projects found" centered message with "Create Project" button
   - Pagination: Show "Showing X-Y of Z projects" with Previous/Next buttons at the bottom using the page/onPageChange/total props. Calculate from offset.
   - Export `ProjectsTable` component

3. Create `apps/web/app/(dashboard)/projects/components/projects-filters.tsx`:
   - Use `useQueryStates` from nuqs with parsers:
     - `search`: `parseAsString` (combined job# and name search)
     - `customer`: `parseAsString` (customer ID filter)
     - `status`: `parseAsStringEnum(['active', 'on_hold', 'completed', 'archived'])`
     - `assignedUser`: `parseAsString` (user ID filter)
     - `startDateFrom`: `parseAsString` (ISO date)
     - `startDateTo`: `parseAsString` (ISO date)
     - `page`: `parseAsInteger.withDefault(1)`
   - Render a horizontal filter bar with:
     a. Search input (text field with magnifying glass icon, 300ms debounce using existing `useDebounce` hook from `@/hooks/use-debounce`)
     b. Status dropdown using shadcn Select (All, Active, On Hold, Completed, Archived)
     c. Customer dropdown using shadcn Select with a "All Customers" default option. Accept a `customers` prop for the options list.
     d. Assigned User dropdown using shadcn Select with "All Users" default. Accept a `users` prop for the options list.
     e. Date range: Two date inputs for From/To
     f. Clear Filters button (only shows when any filter is active, resets all to null and page to 1)
   - When any filter changes, reset page to 1
   - Export the filter state type and the component
   - Use Procore-style compact filter bar: `gap-3`, `items-center`, `flex-wrap` for responsive layout
