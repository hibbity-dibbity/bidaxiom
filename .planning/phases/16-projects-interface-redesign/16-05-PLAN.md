For each section page in `apps/web/app/(dashboard)/projects/[projectId]/`:

1. **Copy** the file to the equivalent path under `[projectSlug]/` (create directories as needed).

2. **Modify** each copied page with these changes:
   a. Change `params: { projectId: string }` to `params: { projectSlug: string }` in the component props
   b. Add a slug-to-id resolution hook at the top of each component. Use a shared pattern:
      ```typescript
      const { data: project } = trpc.project.getBySlug.useQuery(
        { slug: params.projectSlug },
        { enabled: !!params.projectSlug }
      );
      const projectId = project?.id;
      ```
      React Query will return the cached data from the layout's fetch (same query key), so this is instant - no extra API call.
   c. Guard all tRPC calls that need projectId with `{ enabled: !!projectId }`:
      ```typescript
      const { data: budget } = trpc.budget.list.useQuery(
        { projectId: projectId! },
        { enabled: !!projectId }
      );
      ```
   d. Replace all internal link hrefs from `/projects/${projectId}/...` to `/projects/${params.projectSlug}/...`
   e. Remove any breadcrumb navigation that duplicates what the layout provides (the header + tabs in the layout serve this purpose). Keep breadcrumbs only for deeper nesting (e.g., change order detail shows "Change Orders > CO-001").
   f. Remove any page-level h1 headers that duplicate the layout header (the project name/job number is in ProjectHeader)

3. **Pattern for each section page** - the key transformation is:
   - Old: `const { projectId } = params;` then use `projectId` directly
   - New: `const { projectSlug } = params;` then resolve `projectId` via `trpc.project.getBySlug` (cached), then use `projectId` for data queries

4. **For deeply nested pages** (change-orders/[changeOrderId], payment-apps/[paymentAppId], rfqs/[rfqId]):
   - These have both `projectSlug` and their own ID param
   - Update params type to `{ projectSlug: string; changeOrderId: string }` etc.
   - Same slug-to-id pattern applies

5. After all files are created under `[projectSlug]/`, delete the entire `[projectId]/` directory:
   ```bash
   rm -rf "apps/web/app/(dashboard)/projects/[projectId]"
   ```
