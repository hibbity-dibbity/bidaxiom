Rewrite project-header.tsx to the 2-row compact layout. The component signature changes: remove `budgetSummary`, `teamMemberCount`, address/date fields from the project prop; add `headerStats`.

**New interface:**
```tsx
interface ProjectHeaderProps {
  project: {
    id: string;
    jobNumber: string | null;
    name: string;
    slug: string;
    lifecyclePhase: string;
    projectMode: string;
    customerId: string;
    customerSlug?: string | null;
    restoredAt?: string | null;
  };
  headerStats: {
    contractValue: number;
    billedToDate: number;
    paidToDate: number;
    balanceToComplete: number;
    retainageHeld: number;
  } | null;
  canTransition: boolean;
  canDelete?: boolean;
}
```

**Imports to add:**
```tsx
import { CurrencyDisplay } from "@/components/shared/currency-display";
```

**Imports to remove** (no longer needed):
- `MapPin`, `Calendar`, `Building2` from lucide-react (info row removed)
- `formatCurrency` from `@/lib/utils/format` (replaced by CurrencyDisplay)

Keep: `Link`, `Button`, `Badge`, `MoreVertical`, `LifecyclePhaseBadge`, `trpc`, `toast`, `DropdownMenu`, `DropdownMenuContent`, `DropdownMenuTrigger`, `DeleteProjectButton`.

**Add DropdownMenuItem import** (needed for mode switch menu item):
```tsx
import { DropdownMenuItem } from "@/components/ui/dropdown-menu";
```

**New JSX structure (replace the entire return):**
```tsx
return (
  <div className="pb-0">
    {/* Restored banner — renders above rows; accepted transient height when visible */}
    {project.restoredAt && (
      <div className="flex items-center justify-between rounded border border-border bg-muted px-4 py-2 text-sm text-muted-foreground mb-2">
        <span>This project was deleted and restored.</span>
        <Button
          variant="ghost"
          size="sm"
          onClick={() => acknowledgeRestoreMutation.mutate({ projectId: project.id })}
          disabled={acknowledgeRestoreMutation.isPending}
        >
          Dismiss
        </Button>
      </div>
    )}

    {/* Row 1 (~40px): Job # + Name + Lifecycle phase badge + Mode badge + Actions */}
    <div className="flex items-center justify-between mb-1">
      <div className="flex items-center gap-3 min-w-0">
        <h1 className="text-lg font-semibold truncate">
          {project.jobNumber ? `${project.jobNumber} — ${project.name}` : project.name}
        </h1>
        <LifecyclePhaseBadge
          projectId={project.id}
          projectSlug={project.slug}
          currentPhase={project.lifecyclePhase as LifecyclePhase}
          canTransition={canTransition}
        />
        <Badge variant="outline" className="bg-muted text-muted-foreground text-xs shrink-0">
          {project.projectMode === "simple" ? "Simple" : "GC/Advanced"}
        </Badge>
      </div>
      <div className="flex items-center gap-2 shrink-0">
        <DropdownMenu>
          <DropdownMenuTrigger asChild>
            <Button variant="ghost" size="icon" className="h-8 w-8">
              <MoreVertical className="h-4 w-4" />
            </Button>
          </DropdownMenuTrigger>
          <DropdownMenuContent align="end">
            {canTransition && (
              <DropdownMenuItem
                onClick={handleModeSwitch}
                disabled={setModeMutation.isPending}
              >
                {setModeMutation.isPending
                  ? "Switching..."
                  : project.projectMode === "simple"
                  ? "Switch to GC/Advanced"
                  : "Switch to Simple"}
              </DropdownMenuItem>
            )}
            {canDelete && (
              <DeleteProjectButton
                projectId={project.id}
                projectName={project.name}
                variant="menu-item"
                onDeleted={() => {
                  window.location.href = "/projects";
                }}
              />
            )}
          </DropdownMenuContent>
        </DropdownMenu>
        <Button variant="outline" size="sm" asChild>
          <Link href={`/projects/${project.slug}/edit`}>Edit</Link>
        </Button>
      </div>
    </div>

    {/* Row 2 (~40px): Financial stat bar — 5 fields always visible */}
    <div className="flex items-center gap-6 pb-3 overflow-x-auto">
      {[
        { label: "Contract Value", value: headerStats?.contractValue ?? 0 },
        { label: "Billed to Date", value: headerStats?.billedToDate ?? 0 },
        { label: "Paid to Date", value: headerStats?.paidToDate ?? 0 },
        { label: "Balance to Complete", value: headerStats?.balanceToComplete ?? 0 },
        { label: "Retainage Held", value: headerStats?.retainageHeld ?? 0 },
      ].map(({ label, value }) => (
        <div key={label} className="flex flex-col min-w-0 shrink-0">
          <span className="text-xs text-muted-foreground leading-tight whitespace-nowrap">{label}</span>
          <CurrencyDisplay amount={value} className="text-sm font-semibold" />
        </div>
      ))}
    </div>
  </div>
);
```

Keep the `setModeMutation`, `acknowledgeRestoreMutation`, and `handleModeSwitch` logic unchanged — they are still needed.

Remove the `formatCurrencyValue` and `formatDateRange` and `formatAddress` helper functions — they are no longer used.
