**KpiCard component:**

Props interface:
```typescript
interface KpiCardProps {
  title: string;
  value: string | number;
  description?: string;
  icon?: React.ComponentType<{ className?: string }>;
  status?: "success" | "warning" | "error" | "neutral";
  onClick?: () => void;
  className?: string;
}
```

Implementation:
- Use shadcn/ui Card, CardHeader, CardTitle, CardContent (import from `@/components/ui/card`)
- CardHeader: flex row, items-center, justify-between, space-y-0, pb-2
- CardTitle: text-sm font-medium (matches BudgetSummaryCards pattern)
- Icon in header: h-4 w-4 text-muted-foreground
- Value: text-2xl font-bold, apply status color via map:
  - success: text-green-600 dark:text-green-500
  - warning: text-amber-600 dark:text-amber-500
  - error: text-red-600 dark:text-red-500
  - neutral: (no extra class, uses default)
- Description: text-xs text-muted-foreground mt-1
- If onClick provided: Card gets `cursor-pointer hover:shadow-sm transition-shadow`
- Accept className prop for additional Card styling

**MyActiveProjects widget:**

- Icon: FolderKanban (from lucide-react)

- Loading state: return KpiCardSkeleton
- Error state: return KpiCard with value="--" and description="Unable to load"
- onClick: navigate to `/projects` using `useRouter` from next/navigation

**MyOpenBids widget:**
- Uses `trpc.dashboard.myOpenBids.useQuery()`
- Icon: Gavel (from lucide-react)
- Title: "My Open Bids"
- Value: data.count (number)
- Description: `"Awaiting response"` if count > 0, else `"No open bids"`
- Status: count > 0 ? "neutral" : "success"
- Loading/error states same pattern as above

**MyTodo widget:**
- Uses `trpc.dashboard.myTodo.useQuery()`
- Icon: ClipboardCheck (from lucide-react)
- Title: "My To-Do"
- Value: data.count (number)

- Status: count > 0 ? "warning" : "success"
- Loading/error states same pattern

**Important patterns:**
- Each widget is a named export function component
- Each handles loading, error, and data states independently
- Use `{ retry: false }` option on queries to prevent retry spam
