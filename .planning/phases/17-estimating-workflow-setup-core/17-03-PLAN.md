  <name>Task 1: Create estimate templates router with cost code template procedures</name>
  <files>apps/api/src/routers/estimateTemplates.ts</files>
  <action>
Create router for cost code templates and labor rate templates:

**Cost Code Template Procedures:**

1. **listCostCodeTemplates** (authorizedProcedure):
   - Input: { projectType: z.string().optional(), scope: z.enum(['company', 'personal', 'all']).default('all') }
   - Check `can('read', 'EstimateTemplate')`
   - Query tenantSchema.costCodeTemplates
   - Filter: If scope === 'company', where scope = 'company'. If scope === 'personal', where createdBy = userId. If 'all', both.
   - Filter: If projectType provided, where projectType matches OR projectType IS NULL (universal templates)
   - Include count of templateLineItems
   - Return array of templates

2. **getCostCodeTemplateById** (authorizedProcedure):
   - Input: { id: z.string().uuid() }
   - Check `can('read', 'EstimateTemplate')`
   - Query template with lineItems (use .with({ lineItems: true }))
   - Verify user can access (scope === 'company' OR createdBy === userId)
   - Return template with line items

3. **createCostCodeTemplate** (authorizedProcedure):
   - Input: createTemplateSchema
   - Check if scope === 'company': require `can('create', 'EstimateTemplate')` with org:admin role
   - Check if scope === 'personal': query company profile, verify allowPersonalTemplates !== false
   - Insert template with createdBy: userId, isActive: true
   - Return created template

4. **applyCostCodeTemplate** (authorizedProcedure):
   - Input: applyTemplateSchema (templateId, estimateId, overrides)
   - Load abilities via estimate.projectId
   - Check `can('update', 'Estimate')`
   - Begin transaction:
     * Query template with all templateLineItems
     * For each template line item, INSERT new estimateLineItem (deep clone):
       - Generate new UUID for id
       - Set estimateId to input estimateId
       - Copy: costCodeId, description, quantity, unit, costType, orderIndex
       - Set unitCost from estimatedUnitCost (or 0 if null)
       - Set sourceTemplateId to templateId (NO FK constraint - just tracking)
       - Set createdAt, updatedAt to now
     * Update estimate: appliedCostCodeTemplateId = templateId
   - Return { success: true, itemsAdded: count }

5. **deleteCostCodeTemplate** (authorizedProcedure):
   - Input: { id: z.string().uuid() }
   - Query template
   - Verify user can delete: scope === 'personal' AND createdBy === userId, OR can('delete', 'EstimateTemplate') for company templates
   - Delete template (cascade deletes line items)
   - Return { success: true }

**Labor Rate Template Procedures:**

6. **listLaborRateTemplates** (authorizedProcedure):
   - Similar to listCostCodeTemplates but query laborRateTemplates table
   - Filter by scope (company, personal, all)
   - Return array

7. **createLaborRateTemplate** (authorizedProcedure):
   - Input: createLaborRateTemplateSchema (name, description, scope, rates)
   - Check scope permissions (company requires admin, personal requires allowPersonalTemplates)
   - Insert with rates as JSONB
   - Return created template

8. **applyLaborRateTemplate** (authorizedProcedure):
   - Input: { templateId, estimateId }
   - Load abilities
   - Check `can('update', 'Estimate')`
   - Query labor rate template
   - Query all estimateLineItems WHERE estimateId AND costType = 'labor'
   - For each labor line item:
     * Extract labor classification from description (e.g., "Foreman - Site Prep" → "Foreman")
     * Look up rate in template.rates[classification]
     * If found, UPDATE unitCost to rate
   - Update estimate: appliedLaborRateTemplateId = templateId
   - Return { success: true, itemsUpdated: count }

9. **deleteLaborRateTemplate** (authorizedProcedure):
   - Same permission logic as deleteCostCodeTemplate
   - Delete template
   - Return { success: true }

Follow existing error patterns with TRPCError.
