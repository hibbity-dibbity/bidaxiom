  <action>
Add 7 new tables to tenant schema following existing patterns from lines 389-545 (budgets, changeOrders):

1. **estimates** table:
   - id (uuid, primary key)
   - projectId (references projects.id, cascade delete)
   - name (text, not null)
   - description (text, nullable)
   - status (text, not null, default 'draft') - enum: draft, submitted, accepted, under_contract
   - projectType (text, not null) - commercial, residential, infrastructure, industrial
   - appliedCostCodeTemplateId (references costCodeTemplates.id, nullable)
   - appliedLaborRateTemplateId (references laborRateTemplates.id, nullable)
   - overheadType (text, not null, default 'percentage') - percentage or fixed
   - overheadValue (numeric 15,2, not null, default 0)
   - markupBase (text, not null, default 'direct') - direct or direct_plus_overhead
   - directCosts (numeric 15,2, not null, default 0) - denormalized for performance
   - overheadAmount (numeric 15,2, not null, default 0)
   - markupAmount (numeric 15,2, not null, default 0)
   - totalCost (numeric 15,2, not null, default 0)
   - currentVersion (integer, not null, default 1)
   - submittedAt (timestamp with timezone, nullable)
   - acceptedAt (timestamp with timezone, nullable)
   - createdBy (text, not null)
   - createdAt, updatedAt (timestamps)

2. **estimateLineItems** table:
   - id, estimateId (references estimates.id, cascade)
   - costCodeId (integer, not null)
   - description (text, not null)
   - quantity (numeric 15,4, not null)
   - unit (text, not null) - ea, sf, lf, ton, hr
   - unitCost (numeric 15,4, not null)
   - costType (text, not null) - labor, material, equipment, subcontractor
   - customMarkupPercent (numeric 5,2, nullable) - override company defaults
   - sourceTemplateId (uuid, nullable, NO FK) - track origin without constraint
   - orderIndex (integer, not null, default 0)
   - createdAt, updatedAt

3. **costCodeTemplates** table:
   - id, name, description
   - scope (text, not null) - company or personal
   - projectType (text, nullable) - applies to all if null
   - createdBy (text, not null)
   - isActive (boolean, not null, default true)
   - createdAt, updatedAt

4. **templateLineItems** table:
   - id, templateId (references costCodeTemplates.id, cascade)
   - costCodeId, description
   - quantity (numeric 15,4, nullable)
   - unit (text, nullable)
   - estimatedUnitCost (numeric 15,4, nullable)
   - costType (text, not null)
   - orderIndex (integer, default 0)
   - createdAt

5. **laborRateTemplates** table:
   - id, name, description
   - scope (text, not null) - company or personal
   - rates (jsonb, not null) - Record<string, number> for labor classifications
   - createdBy (text, not null)
   - isActive (boolean, default true)
   - createdAt, updatedAt

6. **estimateVersions** table:
   - id, estimateId (references estimates.id, cascade)
   - version (integer, not null)
   - status (text, not null)
   - snapshot (jsonb, not null) - complete estimate + line items + totals
   - createdBy (text, not null)
   - createdAt

7. **sovVersions** table:
   - id, sovId (uuid, not null)
   - estimateVersionId (references estimateVersions.id, nullable)
   - version (integer, not null)
   - status (text, not null) - draft, submitted, accepted, contractual
   - lineItems (jsonb, not null) - array of SOV line items with metadata
   - createdFromChangeOrder (references changeOrders.id, nullable)
   - createdAt

Add all tables to schema export return statement.
Follow existing NUMERIC(15,2) pattern for currency (not DECIMAL).
Follow existing timestamp pattern: defaultNow().notNull() for createdAt, defaultNow().notNull() for updatedAt.
