  <files>apps/api/src/services/estimateCalculations.ts</files>
  <action>
Create calculation service following RESEARCH.md Pattern 4 (Tiered Calculation Engine with Override Cascade).

Functions to implement:

1. **calculateLineItemMarkup(lineItem, config)**:
   - Priority 1: Check lineItem.customMarkupPercent (line item override)
   - Priority 2: Check config.estimateOverrides[lineItem.costType] (estimate-level override)
   - Priority 3: Fall back to config.companyDefaults[`${costType}Markup`]
   - Return markup percentage as number

2. **calculateEstimateTotals(lineItems, markupConfig, overheadConfig)**:
   - Calculate directCosts: sum(quantity * unitCost) for all line items
   - Calculate overhead:
     * If overheadConfig.type === 'percentage': directCosts * (overheadConfig.value / 100)
     * If overheadConfig.type === 'fixed': overheadConfig.value
   - Determine markupBase:
     * If markupConfig.markupBaseType === 'direct_plus_overhead': directCosts + overhead
     * Else: directCosts
   - Calculate totalMarkup: For each line item, itemCost * (markupPercent / 100), summed
   - Calculate totalCost: directCosts + overhead + totalMarkup
   - Calculate margin: (totalMarkup / totalCost) * 100
   - Return { directCosts, overhead, totalMarkup, totalCost, marginPercent, marginDollars: totalMarkup }

Use proper TypeScript types from packages/shared.
Add JSDoc comments explaining calculation order per CONTEXT.md decision: overhead applies to direct costs, markup applies based on markupBase setting.

DO NOT use floating point for money calculations - all inputs are already Drizzle numeric types which are strings. Convert to number only for final calculations and round to 2 decimals.

<task type="auto">

Create `apps/api/src/routers/estimates.ts` following existing patterns from budgets.ts and changeOrders.ts:

1. **list** procedure (authorizedProcedure):
   - Input: { projectId: z.string().uuid() }
   - Load abilities with loadProjectAbilities(projectId)
   - Check `can('read', 'Estimate')`
   - Query tenantSchema.estimates WHERE projectId, include lineItems count
   - Return array with calculated totals (use estimateCalculations service)

2. **getById** procedure (authorizedProcedure):
   - Input: { id: z.string().uuid() }
   - Load project abilities via estimate.projectId
   - Check `can('read', 'Estimate')`
   - Query estimate with lineItems (use Drizzle .with({ lineItems: true }))
   - Return estimate with calculated totals

3. **create** procedure (authorizedProcedure):
   - Input: createEstimateSchema from packages/shared
   - Load abilities for projectId
   - Check `can('create', 'Estimate')`
   - Insert estimate with status: 'draft', currentVersion: 1, createdBy: userId
   - Return created estimate

4. **update** procedure (authorizedProcedure):
   - Input: { id, ...updateEstimateSchema }
   - Load abilities via estimate.projectId
   - Check `can('update', 'Estimate')`
   - If status is changing from draft, throw error "Use submit procedure to change status"
   - Update estimate, set updatedAt to now
   - Recalculate totals from lineItems (query line items, call calculateEstimateTotals, update denormalized fields)
   - Return updated estimate with totals

5. **updateLineItem** procedure (authorizedProcedure):
   - Input: updateLineItemSchema
   - Load abilities via lineItem.estimateId → estimate.projectId
   - Check `can('update', 'Estimate')`
   - Update line item
   - Trigger recalculation of estimate totals (query all lineItems, calculate, update estimate)
   - Return updated line item

6. **submit** procedure (authorizedProcedure):
   - Input: { estimateId: z.string().uuid() }
   - Load abilities
   - Check `can('update', 'Estimate')`
   - Validate estimate status is 'draft'
   - Begin transaction:
     * Query estimate with all lineItems
     * Create estimateVersion snapshot (increment version, store complete estimate + lineItems in JSONB)
     * Update estimate: status = 'submitted', currentVersion++, submittedAt = now
   - Return { success: true, version: newVersion }

7. **delete** procedure (authorizedProcedure):
   - Input: { id: z.string().uuid() }
   - Load abilities
   - Check `can('delete', 'Estimate')`
   - Validate status is 'draft' (only draft estimates can be deleted)
   - Delete estimate (cascade will delete line items via FK)
   - Return { success: true }

Add router to apps/api/src/routers/index.ts:

Follow existing error handling patterns (TRPCError with FORBIDDEN, NOT_FOUND codes).
Use `ctx.userId` for createdBy fields.
