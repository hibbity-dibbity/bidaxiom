**`apps/web/components/integrations/qbo-connection-card.tsx`:**

Create a card component for QuickBooks connection management:
- Uses shadcn/ui Card, Button, Badge components.
- Takes props: `connection` (from tRPC getStatus response), `onConnect`, `onDisconnect`.
- Display states:
  - **Not connected**: Show "QuickBooks Online" heading, "Not connected" badge (gray), description text, and "Connect QuickBooks" primary button.
  - **Connected**: Show "QuickBooks Online" heading, "Connected" badge (green), company name (if available), realm ID, environment (sandbox/production badge), connected date, refresh token expiry date. Show "Disconnect" destructive button with confirmation dialog (use AlertDialog from shadcn/ui).
  - **Error/Expired**: Show "Error" or "Expired" badge (red/yellow), error message, and "Reconnect" button.
- Connect button: calls `trpc.quickbooks.getAuthUrl.mutate()`, then `window.location.href = authUrl` to redirect to QBO OAuth login.
- Disconnect button: calls `trpc.quickbooks.disconnect.mutate()` after confirmation, then invalidates query cache.
- Show last sync timestamp if available, formatted as relative time ("2 hours ago").

**`apps/web/components/integrations/qbo-sync-status.tsx`:**

Create a sync status display component:
- Takes props: `syncStates` array from tRPC getStatus response, `onManualSync` callback.
- Display as a table (shadcn/ui Table) with columns: Entity Type, Status, Last Sync, Synced Count, Errors.
- Entity type: capitalize and format (e.g., "project" -> "Projects").
- Status column: Badge with color based on syncStatus:
  - `synced` -> green "Synced"
  - `syncing` -> blue "Syncing..."
  - `pending` -> gray "Pending"
  - `error` -> red "Error"
  - `conflict` -> yellow "Conflict"
- Last Sync column: formatted datetime or "Never" if null.
- Errors column: show errorCount, if > 0 show as red text with tooltip showing errorMessage.
- Below table: "Sync Now" button group with options: "Sync All", "Sync Projects", "Sync Invoices", "Sync Bills". Use DropdownMenu from shadcn/ui.
- Sync buttons call `trpc.quickbooks.manualSync.mutate({ entityType })`.
- Show loading state while sync is in progress (disable buttons, show spinner).

**`apps/web/app/(dashboard)/settings/integrations/page.tsx`:**

Create the integrations settings page:
- Title: "Integrations" with description "Connect external services to your account."
- Fetch QBO status via `trpc.quickbooks.getStatus.useQuery()`.
- Render QboConnectionCard with connection data.
- If connected, render QboSyncStatus below the card.
- Handle loading and error states.
- Use 5-second polling (refetchInterval) for sync status to provide near-real-time updates when sync is in progress.

**`apps/web/app/(dashboard)/settings/integrations/quickbooks/callback/page.tsx`:**

Create the OAuth callback handler page:
- This page receives `code`, `realmId`, `state` as URL search params (from the API redirect).
- Use `useSearchParams()` to extract params.
- On mount (useEffect), call `trpc.quickbooks.handleCallback.mutate({ code, realmId, state })`.
- Show loading spinner with "Connecting QuickBooks..." text during the mutation.
- On success: show success message ("QuickBooks connected successfully!") and redirect to `/settings/integrations` after 2 seconds via `router.push()`.
- On error: show error message with retry option (link back to integrations page).
- Use `'use client'` directive (requires hooks).
