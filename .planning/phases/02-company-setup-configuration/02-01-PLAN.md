    **1. Create company router** (`apps/api/src/trpc/routers/company.ts`):

    Import `authorizedProcedure` from procedures (for admin-only mutations) and `protectedProcedure` (for read access). Import `companyConfigSchema` from `@construction/shared`. Import `asOfDate` from `../../lib/effective-dating.js`. Import `withAuditLog` from middleware/audit for mutation logging. Import `requirePermission` from middleware/authorize. Import `TRPCError` from `@trpc/server`. Import `isNull`, `and`, `eq`, `desc` from `drizzle-orm`.

    Define these procedures:

    **getCurrent** (protectedProcedure, no input):
    - Query companyProfiles WHERE validTo IS NULL, LIMIT 1
    - Return the profile or null (no profile yet = company hasn't been configured)
    - This is the most common query -- used by the settings page

    **getAsOf** (protectedProcedure, input: `z.object({ asOf: z.date() })`):
    - Query companyProfiles using `asOfDate(schema.companyProfiles.validFrom, schema.companyProfiles.validTo, input.asOf)`
    - LIMIT 1, order by validFrom DESC (get the most recent version valid at that date)
    - Return profile or null
    - This supports COMP-05 -- historical queries for RFQ/bid context

    **update** (authorizedProcedure with requirePermission("manage", "CompanySettings"), input: companyConfigSchema):
    - Business validation: if companyType is "sub_only" and csiDivisions is empty, throw BAD_REQUEST "Subcontractors must select at least one trade"
    - Wrap in transaction (use ctx.tenant.db.transaction):
      1. Close current version: UPDATE companyProfiles SET validTo = now WHERE validTo IS NULL
      2. Insert new version with validFrom = now, validTo = null, createdBy = ctx.userId
    - Use `withAuditLog({ entityType: "CompanyProfile", action: "update" })` middleware on this procedure
    - Return the new profile record

    **getHistory** (protectedProcedure, no input):
    - Query all companyProfiles ordered by validFrom DESC
    - Return array of all versions (for viewing configuration history)

    Export `companyRouter` using `router({...})`.

    **2. Register in root router** (`apps/api/src/trpc/router.ts`):
    - Import `companyRouter` from `./routers/company.js`
    - Add `company: companyRouter` to the appRouter definition

    **Important notes:**
    - The update mutation must use a database transaction to ensure atomicity (close old + insert new)
    - Use `ctx.tenant.db` for all queries (tenant-scoped)
    - Use `ctx.tenant.schema.companyProfiles` for table references
    - The `withAuditLog` middleware from Phase 1 handles audit trail automatically
    - Do NOT use PostgreSQL ENUM for companyType -- use text + Zod validation per research recommendation
