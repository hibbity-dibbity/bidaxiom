- "use client" component showing bid summary
- Displays: bidder company name, total amount (formatted as currency), version count, status badge, submitted date
- Status badge colors: submitted=blue, under_review=yellow, shortlisted=purple, awarded=green, rejected=red, withdrawn=gray
- Click navigates to bid detail or expands to show more info
- "Has unacknowledged amendments" indicator (orange dot/badge) if applicable

**3. RFQ Detail Page (`rfqs/[rfqId]/page.tsx`):**
- "use client" page
- Header: RFQ number + title, status badge, action buttons based on status:
  - Draft: "Edit", "Issue", "Delete" buttons
  - Issued: "Close", "Cancel", "Compare Bids" buttons
  - Closed: "Compare Bids" button
  - Awarded: info only
- Three sections/tabs:
  a. **Overview**: scope of work, trades (displayed as CSI division names), due date, description, attachment references
  b. **Invitations**: InvitationManager component (from Task 1)
  c. **Bids**: list of BidCard components, with "Compare Bids" link to comparison page
  d. **Amendments**: AmendmentTimeline component
- Uses trpc.rfq.getById.useQuery
- Action buttons use respective mutations (trpc.rfq.issue, trpc.rfq.close, trpc.rfq.cancel, trpc.rfq.delete)
- After issue/close/cancel, invalidate queries and show toast
- Delete redirects back to RFQ list

**4. Bid Comparison Table (`components/bidding/bid-comparison-table.tsx`):**
- "use client" component - the core comparison UI
- Uses trpc.bid.compare.useQuery for data
- Layout: horizontal table/grid where each column is a bid, each row is a comparison dimension:
  - Row 1: Bidder name
  - Row 2: Original amount (from current version totalAmount)
  - Row 3: Leveling adjustments (sum of adjustmentAmounts from leveling notes, expandable to show individual notes)
  - Row 4: **Leveled amount** (bold, highlighted - the actual comparison number)
  - Row 5: Scope notes
  - Row 6: Exclusions (highlight differences across bids in red)
  - Row 7: Inclusions
  - Row 8: Line item breakdown (collapsible section showing each line item)
  - Row 9: Actions: "Add Leveling Note" button, "Award" button
- "Add Leveling Note" opens a dialog with: category dropdown (scope_gap, scope_extra, clarification, risk), note text, optional adjustment amount
- "Award" button opens confirmation dialog: "Award to {company}?" with checkbox "Convert to budget commitment" and optional description. Calls trpc.bid.award.useMutation
- Visual highlight: lowest leveled amount gets a green border/background
- Columns should be scrollable horizontally if many bids
