Create apps/api/src/services/report-engine.ts with report execution logic:

**executeReport function:**
- Accept: db, schema, reportDefinition, options (forceRefresh boolean, filters override)
- Check materializedReportData table for cached results where reportDefinitionId matches and expiresAt > NOW()
- If cached and !forceRefresh, return cached data
- Otherwise, call buildReportQuery to generate SQL
- Execute query via Drizzle
- Store result in materializedReportData with expiresAt = NOW() + 1 hour
- Return result with metadata (generatedAt, rowCount, executionTime)

**refreshMaterializedData function:**
- Accept: db, schema, reportDefinitionId?
- If reportDefinitionId provided, refresh that report only
- Otherwise, refresh all active reports
- Delete expired materialized data (expiresAt < NOW())

Create apps/api/src/services/report-query-builder.ts with dynamic query building:

**buildReportQuery function:**
- Accept: db, schema, reportDefinition
- Determine base table from dataSource ('projects' → schema.projects, 'budgets' → schema.budgetLineItems, etc.)
- Apply filters using applyFilters helper
- Apply aggregations using applyAggregations helper
- Add groupBy if specified
- Add sortBy if specified
- Return Drizzle query object (do NOT execute - caller executes)

**applyFilters function:**
- Accept: query, filters (ReportFilter[])
- For each filter, apply Drizzle where condition based on operator:
  - 'equals' → eq(field, value)
  - 'not_equals' → ne(field, value)
  - 'greater_than' → gt(field, value)
  - 'less_than' → lt(field, value)
  - 'contains' → like(field, `%${value}%`)
  - 'in' → inArray(field, value)
  - 'between' → and(gte(field, value[0]), lte(field, value[1]))
  - 'is_null' → isNull(field)
  - 'is_not_null' → isNotNull(field)
- Return modified query

**applyAggregations function:**
- Accept: query, columns (ReportColumn[])
- For columns with aggregation function, apply Drizzle aggregation:
  - 'sum' → sum(field).as(label)
  - 'avg' → avg(field).as(label)
  - 'count' → count(field).as(label)
  - 'min' → min(field).as(label)
  - 'max' → max(field).as(label)
- Return modified query

Create apps/api/src/services/analytics-calculator.ts with financial calculations:

**calculateCostPerformance function:**
- Accept: budgeted (numeric), committed (numeric), actual (numeric), percentComplete (numeric)
- Calculate:
  - budgetAtCompletion = budgeted
  - earnedValue = budgeted * (percentComplete / 100)
  - actualCost = actual
  - costVariance = earnedValue - actualCost
  - costPerformanceIndex = earnedValue / actualCost (handle division by zero)
  - estimateAtCompletion = budgeted / costPerformanceIndex
  - estimateToComplete = estimateAtCompletion - actualCost
  - varianceAtCompletion = budgeted - estimateAtCompletion
- Return CostPerformanceMetrics object

**calculateBudgetVariance function:**
- Accept: budgeted (numeric), committed (numeric), actual (numeric)
- Calculate:
  - variance = budgeted - (committed + actual)
  - variancePercent = (variance / budgeted) * 100
  - status = variancePercent < -20 ? 'critical' : variancePercent < -10 ? 'warning' : 'ok'
- Return BudgetVarianceMetrics object

**projectCashFlow function:**
- Accept: db, schema, projectId, startDate, endDate, periodType ('monthly' | 'quarterly')
- Query payment apps for inflow (approved payments)
- Query commitments for outflow (executed contracts)
- Group by period based on periodType
- Calculate net and cumulative net for each period
- Return CashFlowProjection[] array

Use Drizzle ORM query builder patterns. Import eq, ne, gt, lt, gte, lte, like, inArray, and, isNull, isNotNull, sum, avg, count, min, max from drizzle-orm. Handle numeric values using parseFloat for calculations, return as string for NUMERIC(15,2) compatibility.

   - Input: reportDefinitionSchema (without id, createdBy, timestamps)

   - Returns created report with id

4. **update** - Mutation (requires manage Report)
   - Input: z.object({ id, ...partial reportDefinitionSchema })

   - Deletes associated materialized data (force refresh on next execution)

   - Input: z.object({ id })
   - Deletes report definition (cascades to schedules and materialized data)

6. **execute** - Query
