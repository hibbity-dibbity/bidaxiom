Create apps/web/lib/utils/chart-config.ts with chart helpers:

**getAvailableFields function:**
- Accept: dataSource ('projects' | 'budgets' | 'change_orders' | 'payment_apps' | 'bids' | 'commitments')
- Return array of field definitions with { id, label, dataType ('string' | 'number' | 'date'), aggregatable (boolean) }
- Example for 'budgets': [{ id: 'costCodeId', label: 'Cost Code', dataType: 'number', aggregatable: false }, { id: 'budgetedAmount', label: 'Budgeted Amount', dataType: 'number', aggregatable: true }, ...]

**getFilterOperatorsByType function:**
- Accept: dataType
- Return available operators for type:
  - 'string': ['equals', 'not_equals', 'contains']
  - 'number': ['equals', 'not_equals', 'greater_than', 'less_than', 'between']
  - 'date': ['equals', 'greater_than', 'less_than', 'between']
  - 'boolean': ['equals']

Create apps/api/src/db/seed/report-templates.ts with system templates:

**Report templates to seed:**

1. **Project Status Summary**
   - Type: 'project_status'
   - Data source: 'projects'
   - Columns: [name, status, budget, startDate, endDate, createdBy]
   - Filters: [{ field: 'status', operator: 'equals', value: 'active' }]
   - No chart (table only)

2. **Budget Variance Report**
   - Type: 'budget_variance'
   - Data source: 'budgets'
   - Columns: [projectId (with project name join), costCodeId, budgetedAmount, actualCost, { field: 'variance', aggregation: 'sum', label: 'Total Variance' }]
   - Filters: []
   - Chart: bar chart, X=costCodeId, Y=variance

3. **Payment Status**
   - Type: 'payment_status'
   - Data source: 'payment_apps'
   - Columns: [projectId, applicationNumber, status, totalCompletedAndStored, currentPaymentDue, submittedAt]
   - Filters: [{ field: 'status', operator: 'in', value: ['submitted', 'under_review', 'approved'] }]
   - No chart

4. **Change Order Summary**
   - Type: 'change_order_summary'
   - Data source: 'change_orders'
   - Columns: [projectId, type, status, coNumber, totalAmount, approvedAt]
   - Filters: [{ field: 'status', operator: 'equals', value: 'approved' }]
   - Chart: pie chart, groupBy=type, Y=count

5. **Bid Comparison**
   - Type: 'bid_comparison'
   - Data source: 'bids'
   - Columns: [rfqId, bidderCompanyName, totalAmount, status, submittedAt]
   - Filters: [{ field: 'status', operator: 'in', value: ['submitted', 'under_review'] }]
   - Chart: bar chart, X=bidderCompanyName, Y=totalAmount

6. **Cost Performance**
   - Type: 'cost_performance'
   - Data source: 'budgets'
   - Columns: [projectId, { field: 'budgetedAmount', aggregation: 'sum' }, { field: 'actualCost', aggregation: 'sum' }]
   - GroupBy: projectId
   - No filters
   - Chart: line chart, X=projectId, Y=budgetedAmount and actualCost (two lines)

7. **Commitment Summary**
   - Type: 'commitment_summary'
   - Data source: 'commitments'
   - Columns: [projectId, type, vendorName, totalAmount, status, executedAt]
   - Filters: [{ field: 'status', operator: 'in', value: ['approved', 'executed'] }]
   - Chart: doughnut chart, groupBy=type, Y=sum(totalAmount)

**seedReportTemplates function:**
- Accept: db (Drizzle database instance)
- For each template:
  - Insert into public.report_templates table (NOT tenant-scoped)
  - Set isSystem = true
  - Include definition JSONB
- Use upsert pattern (INSERT ... ON CONFLICT DO UPDATE) to allow re-seeding

NOTE: Report templates should be in PUBLIC schema (not tenant-scoped) since they're system-wide. Need to create report_templates table in public schema if it doesn't exist.

Add to apps/api/src/server.ts startup (after database connection):

```typescript
// Seed report templates (idempotent)
try {
  const { seedReportTemplates } = await import('./db/seed/report-templates.js');
  await seedReportTemplates(db);
  console.log('Report templates seeded');
} catch (error) {
  console.error('Failed to seed report templates:', error);
}
```

Templates should be comprehensive starting points for common reporting needs. Users can create reports from templates and customize filters/columns.
