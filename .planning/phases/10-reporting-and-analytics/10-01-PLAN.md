  <action>
Add four new tables to createTenantSchema in apps/api/src/db/schema/tenant.ts:

**1. reportDefinitions table:**
- id: uuid().primaryKey().defaultRandom()
- name: text().notNull()
- description: text()
- type: text().notNull() (ReportType enum)
- dataSource: text().notNull() ('projects', 'budgets', 'change_orders', 'payment_apps', 'bids', 'commitments')
- filters: jsonb().notNull().default([]).$type<ReportFilter[]>()
- columns: jsonb().notNull().$type<ReportColumn[]>()
- sortBy: jsonb().$type<{ field: string; direction: 'asc' | 'desc' }>()
- groupBy: text()
- chartConfig: jsonb().$type<ReportChartConfig>()
- status: text().notNull().default('active') (ReportStatus enum)
- createdBy: text().notNull()
- createdAt: timestamp({ withTimezone: true }).defaultNow().notNull()
- updatedAt: timestamp({ withTimezone: true }).defaultNow().notNull()

**2. reportTemplates table:**
- id: uuid().primaryKey().defaultRandom()
- name: text().notNull()
- description: text()
- type: text().notNull() (ReportType enum)
- isSystem: boolean().notNull().default(false)
- definition: jsonb().notNull().$type<Partial<ReportDefinition>>()
- previewImageUrl: text()
- createdAt: timestamp({ withTimezone: true }).defaultNow().notNull()

**3. reportSchedules table:**
- id: uuid().primaryKey().defaultRandom()
- reportDefinitionId: uuid().notNull().references(() => reportDefinitions.id, { onDelete: 'cascade' })
- name: text().notNull()
- frequency: text().notNull() (ScheduleFrequency enum)
- dayOfWeek: integer() (0-6, Sunday=0)
- dayOfMonth: integer() (1-31)
- time: text().notNull() (HH:MM format)
- recipients: jsonb().notNull().$type<string[]>()
- format: text().notNull() (ExportFormat enum)
- isActive: boolean().notNull().default(true)
- lastRunAt: timestamp({ withTimezone: true })
- nextRunAt: timestamp({ withTimezone: true })
- createdBy: text().notNull()
- createdAt: timestamp({ withTimezone: true }).defaultNow().notNull()
- updatedAt: timestamp({ withTimezone: true }).defaultNow().notNull()

**4. materializedReportData table:**
- id: uuid().primaryKey().defaultRandom()
- reportDefinitionId: uuid().notNull().references(() => reportDefinitions.id, { onDelete: 'cascade' })
- data: jsonb().notNull().$type<unknown>()
- generatedAt: timestamp({ withTimezone: true }).defaultNow().notNull()
- expiresAt: timestamp({ withTimezone: true }).notNull()

Add to apps/api/src/tenant/provision.ts raw SQL CREATE TABLE statements for all four tables with indexes:
- idx_report_definitions_type on reportDefinitions(type)
- idx_report_definitions_status on reportDefinitions(status)
- idx_report_schedules_next_run on reportSchedules(nextRunAt) WHERE isActive = true
- idx_materialized_report_data_expires on materializedReportData(expiresAt)

Update apps/api/src/tenant/context.ts to expose reportDefinitions, reportTemplates, reportSchedules, materializedReportData in RequestTenantContext.schema.

Use patterns from existing tables (changeOrders, paymentApps, qboConnections) for structure. Import boolean from drizzle-orm/pg-core if needed.
