- Position: After `shareFolder` procedure, before `revokeFolderPermission` (around line 1480)
- Input: getDocumentPermissionsSchema
- Auth: protectedProcedure (project team or document owner)
- Logic:
  1. Verify document exists and get projectId + folderId
  2. Load abilities with loadProjectAbilities(projectId)
  3. Check user has "read" permission on document (either project team or explicit grant)
  4. Query document_permissions table WHERE documentId = input.documentId
  5. For each permission, LEFT JOIN user_profiles to get grantee name/email
  6. LEFT JOIN user_profiles again on grantedBy to get grantor name
  7. Order by grantedAt DESC
  8. Return array of: { userId, user: { firstName, lastName, email }, permissionLevel, expiresAt, grantedBy, grantedByUser: { firstName, lastName }, grantedAt }

**Replace placeholder "Current Shares" section (lines 216-224) with functional implementation:**

**1. Add useQuery for current shares:**
```typescript
const { data: currentShares } = trpc.document.getDocumentPermissions.useQuery(
  { documentId },
  { enabled: open } // Only fetch when dialog is open
);
```

**2. Add revoke mutation:**
```typescript
const revokePermissionMutation = trpc.document.revokeDocumentPermission.useMutation({
  onSuccess: () => {
    toast.success("Permission revoked");
    utils.document.getDocumentPermissions.invalidate({ documentId });
    utils.document.getSharedWithMe.invalidate();
  },
  onError: (error) => {
    toast.error(error.message || "Failed to revoke permission");
  },
});
```

**3. Replace "Current Shares" section with table:**
- Use `<Table>`, `<TableHeader>`, `<TableBody>`, `<TableRow>`, `<TableCell>` from shadcn/ui
- Columns: User (name + email), Permission (badge: "View" or "Edit"), Expires (format with date-fns or "Never"), Action (Revoke button)
- Import Table components: `import { Table, TableBody, TableCell, TableHead, TableHeader, TableRow } from "@/components/ui/table"`
- Display "No one has access to this document yet" when currentShares is empty
- Permission level badge: view = secondary variant, edit = default variant
- Revoke button: size="sm", variant="ghost", calls revokePermissionMutation.mutate({ documentId, userId })
- Show loading spinner if revokePermissionMutation.isLoading for specific row
- Expiration display: `expiresAt ? format(new Date(expiresAt), 'PPP') : 'Never'`
- Position table AFTER the Share button and separator, before dialog close

**4. Add invalidation to shareDocument success:**
- Already invalidates getSharedWithMe
- Add: `utils.document.getDocumentPermissions.invalidate({ documentId });`

**5. Add conditional rendering:**
- Show loading state while fetching: "Loading current shares..."
- Show error state if query fails: "Failed to load shares"
- Show table when data exists

**UX considerations:**

- Use trash icon from lucide-react: `<Trash2 className="h-4 w-4" />`

- Keep section label: "People with access" instead of "Current Shares"

**Do NOT:**
- Do not allow user to revoke their own permission (filter out currentShares where userId === ctx.userId)
- Do not show project team members (they have implicit access) - only show explicit grants
