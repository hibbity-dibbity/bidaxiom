<task type="auto">
  <name>Add document tag management procedures to document router</name>
  <files>
    apps/api/src/trpc/routers/document.ts
  </files>
  <action>
Import new schemas from @construction/shared: createTagSchema, removeTagSchema, searchDocumentsSchema

Add five new procedures to documentRouter following existing patterns:

**1. addTag** (mutation, protectedProcedure):
- Input: createTagSchema
- Verify document exists and user has "update" permission on Document
- Normalize tag (trim, lowercase)
- Check if tag already exists on document (prevent duplicates)
- Insert into document_tags table with userId as createdBy
- Create audit log: AuditAction.UPDATE, entityType: "Document", changes: { tags: { added: [tag] } }
- Return success

**2. removeTag** (mutation, protectedProcedure):
- Input: removeTagSchema
- Verify document exists and user has "update" permission on Document
- Delete from document_tags where documentId and tag match
- Create audit log: AuditAction.UPDATE, entityType: "Document", changes: { tags: { removed: [tag] } }
- Return success

**3. getTags** (query, protectedProcedure):
- Input: { documentId: UUID }
- Verify document exists and user has "read" permission on Document
- Query document_tags where documentId, order by createdAt DESC
- Return array of { tag, createdBy, createdAt }

**4. search** (query, protectedProcedure):
- Input: searchDocumentsSchema
- Load project abilities via loadProjectAbilities helper
- Check user has "read" permission on Document
- Build Drizzle query with filters:
  - WHERE projectId = input.projectId
  - AND name ILIKE %input.query% (if query provided)
  - AND category = input.category (if category provided)
  - AND contentType IN input.contentTypes (if contentTypes provided)
  - If tags provided: LEFT JOIN document_tags, WHERE tag IN input.tags, GROUP BY document.id HAVING COUNT(DISTINCT tag) = input.tags.length (must match ALL tags)
- Select documents with currentVersionId, join to get latest version metadata
- Order by updatedAt DESC
- Limit 100 results
- Return array of document objects

**5. logAccess** (mutation, protectedProcedure):
- Input: { documentId: UUID, action: z.enum(["view", "download"]) }
- Verify document exists and user has "read" permission on Document
- Insert into document_access_logs: documentId, userId, action, ipAddress (from ctx if available), accessedAt (now)
- Return success (no audit log needed - this IS the audit log)

Use existing loadProjectAbilities pattern for permission checks. Follow Phase 3 error handling patterns (TRPCError with NOT_FOUND, FORBIDDEN codes).
