Add four new tables to createTenantSchema function following Phase 5 change order patterns:

**document_workflows table:**
- id: UUID primary key
- documentId: UUID foreign key to documents (on delete cascade) - UNIQUE constraint (one workflow per document)
- workflowType: TEXT not null (rfi, submittal, transmittal)
- workflowNumber: TEXT not null (e.g., "RFI-001", "SUB-024", "TX-012")
- projectId: UUID foreign key to projects (denormalized for queries)
- title: TEXT not null (max 200)
- description: TEXT (nullable, max 2000)
- status: TEXT not null (draft, submitted, under_review, approved, rejected, closed, cancelled)
- priority: TEXT (low, medium, high, urgent) - nullable
- dueDate: TIMESTAMP with timezone (nullable)
- submittedBy: TEXT (Clerk user ID)
- submittedAt: TIMESTAMP with timezone
- responseDocumentId: UUID foreign key to documents (nullable - for response attachments)
- respondedBy: TEXT (Clerk user ID, nullable)
- respondedAt: TIMESTAMP with timezone (nullable)
- createdBy: TEXT not null (Clerk user ID)
- createdAt: TIMESTAMP with timezone
- updatedAt: TIMESTAMP with timezone
- Index on (projectId, workflowType, workflowNumber) for queries
- Index on (projectId, status) for filtered lists

**workflow_approvals table** (follows Phase 5 approval_steps pattern):
- id: UUID primary key
- workflowId: UUID foreign key to document_workflows (on delete cascade)
- stepNumber: INTEGER not null (1, 2, 3... for sequential approval)
- approverUserId: TEXT (nullable - null means any user with role)
- approverRole: TEXT (nullable - project_manager, superintendent, etc.)
- requirementType: TEXT not null (specific_user, any_with_role, all_with_role)
- status: TEXT not null (pending, approved, rejected, skipped)
- reviewedBy: TEXT (Clerk user ID, nullable)
- reviewedAt: TIMESTAMP with timezone (nullable)
- comments: TEXT (nullable, max 1000)
- Unique constraint on (workflowId, stepNumber)

**workflow_counters table** (follows Phase 5 sequential_counters pattern):
- id: UUID primary key
- projectId: UUID foreign key to projects (on delete cascade)
- workflowType: TEXT not null (rfi, submittal, transmittal)
- currentNumber: INTEGER not null default 0
- Unique constraint on (projectId, workflowType)
- Used with SELECT FOR UPDATE for race-free sequential numbering

**workflow_history table** (tracks state changes):
- id: UUID primary key
- workflowId: UUID foreign key to document_workflows (on delete cascade)
- changedBy: TEXT not null (Clerk user ID)
- changedAt: TIMESTAMP with timezone
- fromStatus: TEXT
- toStatus: TEXT not null
- fieldName: TEXT (nullable - for non-status field changes)
- oldValue: TEXT (nullable)
- newValue: TEXT (nullable)
- comment: TEXT (nullable, max 500)
- Index on (workflowId, changedAt DESC) for history queries

Insert all four tables into schema export in createTenantSchema return statement.

**Workflow schemas:**
```typescript
// Approval step definition
export const workflowApprovalStepSchema = z.object({
  stepNumber: z.number().int().positive(),
  approverUserId: z.string().optional(), // for specific_user
  approverRole: z.string().optional(), // for any_with_role or all_with_role
  requirementType: approvalRequirementTypeEnum,
});

// Create workflow
export const createWorkflowSchema = z.object({
  documentId: z.string().uuid(),
  workflowType: documentWorkflowTypeEnum,
  title: z.string().min(1).max(200),
  description: z.string().max(2000).optional(),
  priority: workflowPriorityEnum.optional(),
  dueDate: z.string().datetime().optional(),
  approvalSteps: z.array(workflowApprovalStepSchema).min(1).max(10),
});

// Submit workflow (draft -> submitted)
export const submitWorkflowSchema = z.object({
  workflowId: z.string().uuid(),
});

// Approve/Reject approval step
export const reviewApprovalSchema = z.object({
  approvalId: z.string().uuid(),
  action: z.enum(["approve", "reject"]),
  comments: z.string().max(1000).optional(),
});

// Respond to workflow (attach response document)
export const respondToWorkflowSchema = z.object({
  workflowId: z.string().uuid(),
  responseDocumentId: z.string().uuid(),
  comments: z.string().max(1000).optional(),
});

// Update workflow
export const updateWorkflowSchema = z.object({
  workflowId: z.string().uuid(),
  title: z.string().min(1).max(200).optional(),
  description: z.string().max(2000).optional(),
  priority: workflowPriorityEnum.optional(),
  dueDate: z.string().datetime().nullable().optional(),
  status: workflowStatusEnum.optional(), // for manual status changes
});
```
