**Root Cause Analysis:**

Sidebar bounces left-right rapidly = state conflict between:
1. `useSidebar()` hook state (from shadcn sidebar component)
2. localStorage restoration in useEffect
3. Possible CSS transition timing

**Current code (sidebar.tsx lines 32-46):**

```typescript
// Restore collapse state from localStorage on mount
useEffect(() => {
  setMounted(true);
  const stored = localStorage.getItem(STORAGE_KEY);
  if (stored !== null) {
    setOpen(stored === "true");  // <-- Triggers after mount
  }
}, [setOpen]);

// Persist collapse state changes
useEffect(() => {
  if (mounted) {
    localStorage.setItem(STORAGE_KEY, String(open));
  }
}, [open, mounted]);
```

**Problem:** The restoration effect calls `setOpen()` AFTER component mounts, causing:
1. Initial render with default state
2. Effect runs, calls setOpen()
3. State updates, re-render
4. Second effect writes to localStorage
5. Potential loop or double-update during transition

**Fix Strategy:**

**Option 1 - Initialize from localStorage (preferred):**
```typescript
const STORAGE_KEY = "sidebar-collapsed";

export function AppSidebar() {
  const { setOpen, open } = useSidebar();
  const [mounted, setMounted] = useState(false);

  // Initialize from localStorage on mount (single update)
  useEffect(() => {
    setMounted(true);
    const stored = localStorage.getItem(STORAGE_KEY);
    if (stored !== null && !mounted) {
      // Only set if different from current
      const shouldBeOpen = stored === "true";
      if (shouldBeOpen !== open) {
        setOpen(shouldBeOpen);
      }
    }
  }, []); // Empty deps - run once

  // Persist changes (only after mount)
  useEffect(() => {
    if (mounted) {
      localStorage.setItem(STORAGE_KEY, String(open));
    }
  }, [open, mounted]);

  // ... rest
}
```

**Option 2 - Debounce localStorage writes:**
```typescript
import { useEffect, useState, useRef } from "react";

export function AppSidebar() {
  const { setOpen, open } = useSidebar();
  const [mounted, setMounted] = useState(false);
  const initializedRef = useRef(false);

  // Restore on mount
  useEffect(() => {
    setMounted(true);
    if (!initializedRef.current) {
      const stored = localStorage.getItem(STORAGE_KEY);
      if (stored !== null) {
        setOpen(stored === "true");
      }
      initializedRef.current = true;
    }
  }, [setOpen]);

  // Debounced persist
  useEffect(() => {
    if (mounted && initializedRef.current) {
      const timeout = setTimeout(() => {
        localStorage.setItem(STORAGE_KEY, String(open));
      }, 50); // Small delay prevents rapid writes during animation
      return () => clearTimeout(timeout);
    }
  }, [open, mounted]);

  // ... rest
}
```
