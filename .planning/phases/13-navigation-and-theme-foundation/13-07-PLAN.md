**Issue 1: Layout Shift**

Current code (lines 94-96):
```typescript
{isLoading && debouncedQuery && (
  <div className="py-6 text-center text-sm">Searching...</div>
)}
```

Problem: Conditional text renders without reserved space, causing search box to move up/down.

**Fix:** Replace conditional text with inline spinner or fixed-height container:
```typescript
{isLoading && debouncedQuery && (
  <div className="py-6 text-center text-sm min-h-[88px]">
    <Loader2 className="mx-auto h-4 w-4 animate-spin" />
  </div>
)}
```

OR use CommandEmpty with fixed state:
```typescript
{debouncedQuery && results?.length === 0 && (
  <CommandEmpty>
    {isLoading ? (
      <div className="flex items-center justify-center">
        <Loader2 className="mr-2 h-4 w-4 animate-spin" />

      </div>

    )}
  </CommandEmpty>
)}
```

Import Loader2 from lucide-react if using spinner.
