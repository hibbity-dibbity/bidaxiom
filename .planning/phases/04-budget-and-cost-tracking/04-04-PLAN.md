**budget-summary-cards.tsx** — Summary cards showing key budget metrics:
- "use client" directive
- Props: `{ summary: BudgetSummary }` (import type from @construction/shared)
- Render 4 cards in a responsive grid (grid-cols-1 sm:grid-cols-2 lg:grid-cols-4):
  1. **Total Budget**: formatted currency, blue accent
  2. **Committed**: formatted currency, amber accent, percentage of budget
  3. **Remaining**: budget - committed, green if positive, red if negative
  4. **Commitments**: count of commitments
- Use `Intl.NumberFormat('en-US', { style: 'currency', currency: 'USD' })` for formatting
- Use shadcn Card component for each metric
- Include a small progress bar (shadcn Progress) showing committed/budget ratio

**budget-variance-chart.tsx** — Recharts bar chart for cost code variance:
- "use client" directive
- Props: `{ data: VarianceAlert[] }` (import type from @construction/shared)
- Import from recharts: `BarChart, Bar, XAxis, YAxis, CartesianGrid, Tooltip, Legend, ResponsiveContainer, Cell`
- Map data to chart format: `{ name: "Div {costCodeId}", budgeted, committed, variance }`
- Render stacked/grouped BarChart:
  - Blue bars for budgeted amounts
  - Amber bars for committed amounts
  - Color-code variance: green (under budget), red (over budget)
- YAxis formatted with currency (Intl.NumberFormat, minimumFractionDigits: 0)
- Responsive container at 100% width, 400px height
- Tooltip shows full amounts formatted as currency
- Handle empty state: show "No budget data yet" message
- Use CSI_DIVISIONS from @construction/shared to look up division names for labels

**forecast-metrics.tsx** — EVM metric display:
- "use client" directive
- Props: `{ metrics: ForecastMetrics }` (import type from @construction/shared)
- Render 4 metric cards in a grid:
  1. **CPI (Cost Performance Index)**: Show as decimal (e.g., 0.95). Color: green > 1.0, amber 0.8-1.0, red < 0.8. Include explanation: "> 1.0 = under budget"
  2. **EAC (Estimate at Completion)**: Formatted currency. Compare to BAC with arrow indicator.
  3. **ETC (Estimate to Complete)**: Formatted currency. "Remaining cost to finish."
  4. **VAC (Variance at Completion)**: Formatted currency. Green positive (under budget), red negative (over budget).
- Use shadcn Card components with colored borders/accents based on values
- Handle zero/initial state gracefully (CPI = 1.0, all others 0)

  - Vendor Name: text input
  - Contract Number: text input (optional)

    - Cost Code: auto-filled from selected budget line item, or manual entry

    - Amount: number input with currency formatting
    - Remove button per row
    - Add Line Item button
  - Total: calculated sum displayed (read-only)

- On success: invalidate commitment queries, call onSuccess callback, show success toast
