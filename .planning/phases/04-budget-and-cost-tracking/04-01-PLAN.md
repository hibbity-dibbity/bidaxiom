Add three new tables to `createTenantSchema()` in `tenant.ts`:

1. **budget_line_items** table:
   - `id`: UUID PK defaultRandom
   - `projectId`: UUID NOT NULL, references projects.id ON DELETE CASCADE
   - `costCodeId`: integer NOT NULL (0-49 for CSI divisions, 50+ for custom)
   - `description`: text NOT NULL
   - `budgetedAmount`: numeric(15, 2) NOT NULL — CRITICAL: use `numeric` from drizzle, NOT number
   - `isLocked`: boolean NOT NULL default false
   - `lockedAt`: timestamp with timezone, nullable
   - `lockedBy`: text, nullable (Clerk user ID who triggered lock)
   - `createdBy`: text NOT NULL
   - `createdAt`: timestamp with timezone, defaultNow, NOT NULL
   - `updatedAt`: timestamp with timezone, defaultNow, NOT NULL

2. **commitments** table:
   - `id`: UUID PK defaultRandom
   - `projectId`: UUID NOT NULL, references projects.id ON DELETE CASCADE
   - `type`: text NOT NULL — 'subcontract' or 'purchase_order'
   - `vendorName`: text NOT NULL
   - `contractNumber`: text, nullable
   - `description`: text, nullable
   - `totalAmount`: numeric(15, 2) NOT NULL
   - `status`: text NOT NULL default 'draft' — draft, pending, approved, executed, closed
   - `executedAt`: timestamp with timezone, nullable
   - `approvedBy`: text, nullable
   - `approvedAt`: timestamp with timezone, nullable
   - `createdBy`: text NOT NULL
   - `createdAt`: timestamp with timezone, defaultNow, NOT NULL
   - `updatedAt`: timestamp with timezone, defaultNow, NOT NULL

3. **commitment_line_items** table:
   - `id`: UUID PK defaultRandom
   - `commitmentId`: UUID NOT NULL, references commitments.id ON DELETE CASCADE
   - `budgetLineItemId`: UUID, nullable, references budgetLineItems.id ON DELETE SET NULL
   - `costCodeId`: integer NOT NULL (mirrors budget line item cost code for denormalization)
   - `description`: text NOT NULL
   - `amount`: numeric(15, 2) NOT NULL
   - `createdAt`: timestamp with timezone, defaultNow, NOT NULL

Import `boolean` from `drizzle-orm/pg-core` (add to existing import). Return all three new tables from createTenantSchema().
