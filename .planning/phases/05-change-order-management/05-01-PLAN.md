Add 5 new tables to `createTenantSchema()` in tenant.ts, following the exact patterns established in Phase 4 (NUMERIC(15,2) for currency, UUID PKs, proper references, timestamps):

**1. changeOrders table:**
```
id: uuid PK defaultRandom
projectId: uuid NOT NULL references projects(id) ON DELETE CASCADE
type: text NOT NULL  -- 'owner', 'internal', 'subcontractor'
status: text NOT NULL default 'draft'  -- draft, pco_submitted, pending_approval, approved, rejected, void
pcoNumber: text  -- e.g., "PCO-2024-001" (assigned on submit)
coNumber: text   -- e.g., "CO-2024-001" (assigned on approval)
title: text NOT NULL
description: text NOT NULL
reason: text  -- for internal COs: error, efficiency, value_engineering, other
commitmentId: uuid references commitments(id) ON DELETE SET NULL  -- for subcontractor COs
requestedBy: text  -- for owner COs: who requested the change
totalAmount: numeric(15,2) NOT NULL default '0'
relatedDocuments: jsonb default '[]'  -- array of document IDs from Phase 3
submittedAt: timestamp
submittedBy: text
approvedAt: timestamp
approvedBy: text
rejectedAt: timestamp
rejectedBy: text
rejectionReason: text
createdBy: text NOT NULL
createdAt: timestamp defaultNow NOT NULL
updatedAt: timestamp defaultNow NOT NULL
```

**2. changeOrderLineItems table:**
```
id: uuid PK defaultRandom
changeOrderId: uuid NOT NULL references changeOrders(id) ON DELETE CASCADE
budgetLineItemId: uuid references budgetLineItems(id) ON DELETE SET NULL
costCodeId: integer NOT NULL
description: text NOT NULL
amountChange: numeric(15,2) NOT NULL  -- positive = increase, negative = decrease
createdAt: timestamp defaultNow NOT NULL
```

**3. changeOrderCounters table (for scoped sequential numbering):**
```
id: uuid PK defaultRandom
projectId: uuid NOT NULL references projects(id) ON DELETE CASCADE
type: text NOT NULL  -- 'pco' or 'co'
year: integer NOT NULL
lastNumber: integer NOT NULL default 0
```
Note: No unique constraint in Drizzle ORM — uniqueness enforced via SELECT FOR UPDATE in the service layer.

**4. approvalWorkflowSteps table:**
```
id: uuid PK defaultRandom
changeOrderId: uuid NOT NULL references changeOrders(id) ON DELETE CASCADE
stepOrder: integer NOT NULL  -- 1, 2, 3...
approverRole: text  -- normalized Clerk role e.g., "org:project_manager"
approverUserId: text  -- specific user or null = any with role
requirementType: text NOT NULL default 'all'  -- 'all', 'any', 'specific'
status: text NOT NULL default 'pending'  -- pending, approved, rejected, skipped
approvedBy: text
approvedAt: timestamp
comments: text
```

**5. changeOrderHistory table (field-level audit trail):**
```
id: uuid PK defaultRandom
changeOrderId: uuid NOT NULL references changeOrders(id) ON DELETE CASCADE
revisionNumber: integer NOT NULL
changedBy: text NOT NULL
changedAt: timestamp defaultNow NOT NULL
changeType: text NOT NULL  -- 'field_update', 'status_change', 'approval', 'line_item_change'
fieldName: text  -- e.g., 'description', 'totalAmount'
oldValue: jsonb
newValue: jsonb
comments: text
```

Define these Zod schemas and TypeScript types:

```typescript
export const changeOrderTypeEnum = z.enum(["owner", "internal", "subcontractor"]);
export type ChangeOrderType = z.infer<typeof changeOrderTypeEnum>;

export const changeOrderStatusEnum = z.enum([
  "draft", "pco_submitted", "pending_approval", "approved", "rejected", "void"
]);
export type ChangeOrderStatus = z.infer<typeof changeOrderStatusEnum>;

export const internalReasonEnum = z.enum(["error", "efficiency", "value_engineering", "other"]);
export type InternalReason = z.infer<typeof internalReasonEnum>;

export const approvalStepStatusEnum = z.enum(["pending", "approved", "rejected", "skipped"]);
export type ApprovalStepStatus = z.infer<typeof approvalStepStatusEnum>;

export const changeHistoryTypeEnum = z.enum([
  "field_update", "status_change", "approval", "line_item_change"
]);
export type ChangeHistoryType = z.infer<typeof changeHistoryTypeEnum>;
```

2. **Line item schema (shared across all CO types):**
```typescript
export const changeOrderLineItemSchema = z.object({
  budgetLineItemId: z.string().uuid().optional(),
  costCodeId: z.number().int().min(0),
  description: z.string().min(1).max(500),
  amountChange: z.number(), // positive = increase, negative = decrease
});
```

3. **Discriminated union for CO creation:**
```typescript
export const createOwnerChangeOrderSchema = z.object({
  type: z.literal("owner"),
  projectId: z.string().uuid(),
  title: z.string().min(1).max(200),
  description: z.string().min(1).max(5000),
  requestedBy: z.string().min(1).max(200),
  relatedDocuments: z.array(z.string().uuid()).default([]),
  lineItems: z.array(changeOrderLineItemSchema).min(1),
});

export const createInternalChangeOrderSchema = z.object({
  type: z.literal("internal"),
  projectId: z.string().uuid(),
  title: z.string().min(1).max(200),
  description: z.string().min(1).max(5000),
  reason: internalReasonEnum,
  relatedDocuments: z.array(z.string().uuid()).default([]),
  lineItems: z.array(changeOrderLineItemSchema).min(1),
});

export const createSubcontractorChangeOrderSchema = z.object({
  type: z.literal("subcontractor"),
  projectId: z.string().uuid(),
  title: z.string().min(1).max(200),
  description: z.string().min(1).max(5000),
  commitmentId: z.string().uuid(),
  relatedDocuments: z.array(z.string().uuid()).default([]),
  lineItems: z.array(changeOrderLineItemSchema).min(1),
});

export const createChangeOrderSchema = z.discriminatedUnion("type", [
  createOwnerChangeOrderSchema,
  createInternalChangeOrderSchema,
  createSubcontractorChangeOrderSchema,
]);
```

4. **Update schema:**
```typescript
export const updateChangeOrderSchema = z.object({
  id: z.string().uuid(),
  title: z.string().min(1).max(200).optional(),
  description: z.string().min(1).max(5000).optional(),
  requestedBy: z.string().min(1).max(200).optional(),
  reason: internalReasonEnum.optional(),
  relatedDocuments: z.array(z.string().uuid()).optional(),
});
```

5. **Approval action schemas:**
```typescript
export const submitForApprovalSchema = z.object({

  })).min(1),
```
