    **apps/api/src/trpc/routers/notes.ts** — Create a new router file following the same import and pattern as project.ts. Use `protectedProcedure` from `../procedures.js`.

    Three procedures:

    **`notes.list`** (query):
    - Input: `z.object({ projectId: z.string().uuid() })`
    - Query `projectNotes` LEFT JOIN `userProfiles` ON `projectNotes.userId = userProfiles.clerkUserId`
    - Select: `id`, `content`, `createdAt`, `userId` from projectNotes; `firstName`, `lastName` from userProfiles
    - WHERE: `projectNotes.projectId = input.projectId`
    - ORDER BY: `projectNotes.createdAt DESC` (reverse chronological)
    - Return array of `{ id, content, createdAt, userId, authorName }` where `authorName = firstName + ' ' + lastName` (computed via sql template or in JS — prefer JS: `(firstName ?? '') + (lastName ? ' ' + lastName : '') || 'Unknown'`)

    **`notes.create`** (mutation):
    - Input: `z.object({ projectId: z.string().uuid(), content: z.string().min(1).max(500) })`
    - Insert into `projectNotes`: `{ projectId: input.projectId, userId: ctx.userId, content: input.content }`
    - Return the inserted row (`.returning()`)
    - No special auth check beyond protectedProcedure — any authenticated org member can add notes

    **`notes.delete`** (mutation):
    - Input: `z.object({ noteId: z.string().uuid() })`
    - Fetch the note first: `SELECT userId FROM project_notes WHERE id = input.noteId`
    - If not found: throw `TRPCError({ code: 'NOT_FOUND' })`
    - If `note.userId !== ctx.userId AND ctx.orgRole !== 'org:admin'`: throw `TRPCError({ code: 'FORBIDDEN', message: 'You can only delete your own notes' })`
    - Delete the note: `DELETE FROM project_notes WHERE id = input.noteId`
    - Return `{ success: true }`

    All three procedures need the standard tenant null check at the top:
    ```ts
    if (!ctx.tenant || !ctx.userId) {
      throw new TRPCError({ code: 'INTERNAL_SERVER_ERROR', message: 'Tenant context missing' });
    }
    const { db, schema } = ctx.tenant;
    ```

    ```ts
    // In appRouter:
    notes: notesRouter,
    ```
