    **Add state variables** near the top of the component (with the other useState calls):
    ```tsx
    const [noteContent, setNoteContent] = useState("");
    const NOTE_MAX = 500;
    ```

    **Add tRPC hooks** (after the existing query/mutation blocks):
    ```tsx
    const { data: notesData, isLoading: notesLoading } = trpc.notes.list.useQuery(
      { projectId },
      { enabled: !!projectId }
    );

    const createNoteMutation = trpc.notes.create.useMutation({
      onSuccess: () => {
        utils.notes.list.invalidate({ projectId });
        setNoteContent("");
        toast.success("Note added");
      },
      onError: (error) => {
        toast.error(error.message || "Failed to add note");
      },
    });

    const deleteNoteMutation = trpc.notes.delete.useMutation({
      onSuccess: () => {
        utils.notes.list.invalidate({ projectId });
        toast.success("Note deleted");
      },
      onError: (error) => {
        toast.error(error.message || "Failed to delete note");
      },
    });
    ```

    Also add `currentUserId` for own-note detection. The current user id is available as `ctx.userId` on the server, but on the client use Clerk's `useUser()` — however since this project uses a custom auth system (not Clerk hooks on the client), instead pass the userId from the project data. Looking at the existing page.tsx, there's no client-side userId exposed. Use a different approach: the API's `notes.delete` enforces ownership; on the client, show the trash icon on ALL notes (the server will return 403 if they try to delete another user's note and are not admin). This is simpler and correct.

    **Notes JSX section** — Add as the third section in the root `space-y-8` div:

    ```tsx
    {/* Notes */}
    <div>
      {/* Note list (above the input, reverse-chron from API) */}
      <div className="space-y-3 mb-4">
        {notesLoading && (
          <p className="text-sm text-muted-foreground">Loading notes...</p>
        )}
        {notesData && notesData.length === 0 && null /* empty state: just show the input */}
        {notesData?.map((note: any) => (
          <div key={note.id} className="group flex items-start gap-2">
            <div className="flex-1 min-w-0">
              <p className="text-sm whitespace-pre-wrap break-words">{note.content}</p>
              <p className="text-xs text-muted-foreground mt-0.5">
                {note.authorName} &middot;{" "}
                {new Date(note.createdAt).toLocaleString(undefined, {
                  month: "short",
                  day: "numeric",
                  year: "numeric",
                  hour: "numeric",
                  minute: "2-digit",
                })}
              </p>
            </div>
            <Button
              variant="ghost"
              size="icon"
              className="h-6 w-6 opacity-0 group-hover:opacity-100 shrink-0 mt-0.5"
              onClick={() => deleteNoteMutation.mutate({ noteId: note.id })}
              disabled={deleteNoteMutation.isPending}
            >
              <Trash2 className="h-3.5 w-3.5 text-destructive" />
            </Button>
          </div>
        ))}
      </div>

      {/* Input area at bottom */}
      <div className="space-y-2">
        <Textarea
          value={noteContent}
          onChange={(e) => setNoteContent(e.target.value.slice(0, NOTE_MAX))}
          placeholder="Add a note..."
          className="resize-none min-h-[80px]"
          rows={3}
        />
        <div className="flex items-center justify-between">
          <span className={`text-xs ${noteContent.length >= NOTE_MAX - 50 ? "text-destructive" : "text-muted-foreground"}`}>
            {noteContent.length}/{NOTE_MAX}
          </span>
          <Button
            size="sm"
            onClick={() => {
              if (!noteContent.trim()) return;
              createNoteMutation.mutate({ projectId, content: noteContent.trim() });
            }}
            disabled={createNoteMutation.isPending || !noteContent.trim()}
          >
            {createNoteMutation.isPending ? "Adding..." : "Add Note"}
          </Button>
        </div>
      </div>
    </div>
    ```
