In packages/shared/src/schemas/common.ts, update the addressSchema state field (line 29):

**Current (broken):**
```typescript
state: z.string().length(2).optional(), // Two-letter state abbreviation
```

**Updated (working):**
```typescript
state: z
  .string()
  .optional()
  .refine(
    (val) => {
      if (!val || val === "") return true; // Empty is valid
      return val.length === 2; // Must be exactly 2 characters if provided
    },
    {
      message: "State must be a 2-letter abbreviation",
    }
  ),
```

**Why this works:**
- `.optional()` allows undefined
- `.refine()` custom validator accepts empty strings (`val === ""`)
- When state IS provided, validates it's exactly 2 characters
- Matches the established phoneSchema pattern (lines 8-19)

**Why the old pattern failed:**
- `z.string().length(2).optional()` means: "if value exists, it MUST be exactly 2 chars"
- Empty string `""` exists but is 0 chars, not 2 → validation fails
- The Select component in AddressInput (line 88) passes `""` when no selection made, not undefined

Do NOT change anything else in this file. The phoneSchema, addressSchema export, and Address type remain unchanged.
