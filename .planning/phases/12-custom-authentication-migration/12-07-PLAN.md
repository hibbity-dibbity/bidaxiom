For sign-out, create a small form that posts to an API route handler:

Create `apps/web/app/api/auth/logout/route.ts`:
```typescript
import { NextResponse } from "next/server";
import { getSession } from "@/lib/session";

export async function POST() {
  const session = await getSession();
  session.destroy();
  return NextResponse.json({ success: true });
}
```

The UserMenu's sign-out button should call this route then redirect to /sign-in.

Remove Clerk `CreateOrganization`, `useOrganizationList` imports. Build custom onboarding:

- "use client" page
- Use `useAuth()` to check if user has orgs
- Use `trpc.organization.list.useQuery()` to check existing orgs
- If user already has orgs: redirect to "/" (same logic as before)
- If no orgs: show "Create Your Company" form with:
  - Company name input (required, 3-100 chars)

- Style: Match existing settings page patterns (h1, description, card containers)
