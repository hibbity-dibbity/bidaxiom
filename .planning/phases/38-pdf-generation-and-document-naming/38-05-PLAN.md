    **Create `apps/api/src/pdf/templates/payment-app.ts`:**

    Export `buildPaymentAppHtml(data: PaymentAppPdfData): string`.

    PaymentAppPdfData interface:
    ```typescript
    interface PaymentAppPdfData {
      // Project + party info (G702 header)
      companyName: string;          // Contractor name (from tenants.name)
      ownerName: string;            // Customer contactName or companyName
      ownerAddress: string;
      projectName: string;
      projectAddress: string;
      architectName: string;        // "Not specified" if no architect field
      applicationNumber: number;
      periodFrom: string;           // Formatted date
      periodTo: string;             // Formatted date
      contractDate: string;         // project.startDate formatted, or "Not specified"

      // G702 payment lines (all formatted currency strings)
      originalContractSum: string;
      netChangeByChangeOrders: string;
      contractSumToDate: string;
      totalCompletedAndStored: string;
      retainagePercent: string;     // e.g., "10.00%"
      retainageAmount: string;
      totalEarnedLessRetainage: string;
      previousPayments: string;
      currentPaymentDue: string;
      balanceToFinish: string;

      // G703 line items
      lineItems: Array<{
        itemNumber: string;
        description: string;
        scheduledValue: string;
        previousWorkCompleted: string;  // Calculated: previousPercentComplete * scheduledValue
        thisperiodWork: string;
        materialsStored: string;
        totalCompletedAndStored: string;
        balanceToFinish: string;
        retainagePercent: string | null;  // Only show if differs from header rate
      }>;
      uniformRetainage: boolean;    // true = all line items same rate, omit Column I
    }
    ```

    HTML template requirements:
    - All styles inline — no external CSS
    - **G702 Page** (page 1):
      - Title block: "APPLICATION AND CERTIFICATE FOR PAYMENT" in header (standard AIA wording)
      - Project/owner/architect/contractor info in a 2-column grid at top
      - Application number, period from/to, contract date
      - Payment table: 9 numbered lines as specified in RESEARCH.md G702 field reference (Lines 1-9)
      - Certification section: contractor certification text (standard AIA wording: "The undersigned Contractor certifies that to the best of the Contractor's knowledge, information, and belief the Work covered by this Application for Payment has been completed in accordance with the Contract Documents...")
      - Signature block: Contractor Signature with Name/Title/Date fields
      - Architect certificate section: "Certificate Amount", Architect Signature
    - **G703 Page** (page 2, use CSS `page-break-before: always`):
      - Title: "CONTINUATION SHEET" in header
      - Application reference: "Application No. [N]", "Period To: [date]"
      - Table columns: A (Item No.), B (Description of Work), C (Scheduled Value), D (Work Completed - Previous), E (Work Completed - This Period), F (Materials Presently Stored), G (Total Completed D+E+F), H (Balance to Finish C-G)
      - Only render Column I if `uniformRetainage === false`
      - Totals row at bottom
    - Brand colors: slate-blue `#3B5BDB` header bar; use a compact 11px font for G703 table to fit more rows per page
    - Important: AIA documents have a specific 2-page structure — G702 on page 1, G703 on page 2

    **Add `generatePaymentApp` to `apps/api/src/trpc/routers/pdf.ts`:**

    Input schema:
    ```typescript
    z.object({
      projectSlug: z.string(),
      paymentAppId: z.string().uuid(),
    })
    ```

    Procedure implementation:
    1. Look up project by slug (include customer join for owner info).
    2. Look up payment app by id. Verify it belongs to this project. Throw NOT_FOUND if missing.
    3. Look up payment_app_line_items joined with sov_items (for itemNumber, description, scheduledValue).
    4. Look up customer (owner) from project.customerId.
    5. Get company name from `public.tenants`.
    6. Get `documentNamingSettings` from companyProfile (validTo IS NULL).
    7. Call `getNextDocumentSequence(db, schema, tenantId, "payment_app")`.
    8. Call `resolveFileName(documentNamingSettings, "payment_app", project.jobNumber, project.name, seq)`.
    9. Compute `previousWorkCompleted` for each line item: `parseFloat(sovItem.scheduledValue) * (lineItem.previousPercentComplete / 100)` (check actual field names in schema).
    10. Check if retainage is uniform: `uniformRetainage = lineItems.every(li => li.retainagePercent === lineItems[0].retainagePercent)`.
    11. Format all currency values with `Intl.NumberFormat('en-US', { style: 'currency', currency: 'USD' })`.
    12. Call `buildPaymentAppHtml(data)`.
    13. Call `generatePdfBuffer(html)`.
    14. Call `uploadPdfAndSave({ ..., category: "payment_app", description: `Payment Application #${payApp.applicationNumber}` })`.
    15. Return `{ documentId, fileName, message: "Payment Application PDF generated successfully" }`.

    Verify field names by reading the actual payment_app_line_items and sov_items table definitions in tenant.ts before writing the query.
