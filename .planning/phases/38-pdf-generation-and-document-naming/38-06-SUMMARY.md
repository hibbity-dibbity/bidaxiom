# Phase 38 Plan 06: RFQ PDF Feature Summary

**One-liner:** buildRfqHtml template with scopeOfWork pre-wrap rendering and subcontractor response block, pdf.generateRfq tRPC procedure saving to document library with category "rfq", and Generate RFQ PDF button on the RFQ detail page.

## What Was Built

Completed the fourth and final PDF document type for Phase 38:

1. **`apps/api/src/pdf/templates/rfq.ts`** — `buildRfqHtml(data: RfqPdfData)`:
   - Header: company name, "Request for Quotation" label, RFQ number, date issued — slate-blue `#3B5BDB` background
   - Project information section: project name, job number, project address (3-column grid)
   - RFQ title block and optional description section
   - Scope of Work section: free-text block with `white-space: pre-wrap` + left border accent — preserves all line breaks
   - Submission deadline section (blue callout box): shows formatted dueDate or "To be confirmed"
   - Payment Terms section: hardcoded "Net 30 from receipt of approved invoice" with TODO comment for future `rfqs.paymentTerms` field
   - Response Instructions section: standard text instructing subs to include company name, license number, and total bid
   - Subcontractor Response block (detach-and-return): Company Name, License #, Total Bid Amount, Date, Authorized Signature, Printed Name & Title — all as printed fill-in lines
   - Footer: "Issued by [companyName] — Generated by BIDAXIOM"
   - All user-supplied strings passed through `escapeHtml()` for XSS safety

2. **`generateRfq` procedure in `apps/api/src/trpc/routers/pdf.ts`**:
   - Input: `{ projectSlug: string, rfqId: string (uuid) }`
   - Looks up project by slug; verifies RFQ belongs to project
   - Gets company name from `public.tenants`
   - Gets `documentNamingSettings` from active `companyProfiles` row
   - Calls `getNextDocumentSequence(db, schema, "rfq")` for atomic counter increment
   - Calls `resolveFileName()` for PDF file naming
   - Formats `rfq.dueDate` as "Month DD, YYYY" for the deadline display
   - Uses `rfq.rfqNumber` directly from schema (no fabrication)
   - Calls `buildRfqHtml()`, `generatePdfBuffer()`, `uploadPdfAndSave()` with `category: "rfq"`
   - Returns `{ documentId, fileName, message }`

3. **RFQ detail page button** (`apps/web/app/(dashboard)/projects/[projectSlug]/rfqs/[rfqId]/page.tsx`):
   - `trpc.pdf.generateRfq.useMutation` with `toast.success` / `toast.error`
   - "Generate RFQ PDF" button with `FileDown` icon (outline variant)
   - Loading spinner while pending; button disabled during mutation
   - No status gate — button always visible regardless of RFQ status
