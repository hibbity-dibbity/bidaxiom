  <action>
    **Create `apps/api/src/pdf/templates/change-order.ts`:**

    Export `buildChangeOrderHtml(data: ChangeOrderPdfData): string`.

    ChangeOrderPdfData interface:
    ```typescript
    interface ChangeOrderPdfData {
      companyName: string;
      projectName: string;
      jobNumber: string | null;
      projectAddress: string;
      coNumber: string;         // e.g., "CO-003"
      coTitle: string;
      coDescription: string;
      status: string;           // "Pending" | "Approved" | "Rejected"
      generatedDate: string;
      laborCost: string;        // Formatted currency
      materialsCost: string;
      equipmentCost: string;
      subcontractorCost: string;
      totalCost: string;
      contractSumBefore: string;
      contractSumAfter: string;
      scheduleImpactDays: number | null;  // null = no schedule impact
      lineItems: Array<{
        description: string;
        costType: string;       // "Labor" | "Materials" | "Equipment" | "Subcontractor"
        quantity: string;
        unit: string;
        unitCost: string;
        total: string;
      }>;
    }
    ```

    HTML template requirements:
    - All styles inline in `<style>` block — no external CSS
    - Header: company name, "CHANGE ORDER" document type label, CO number and status badge, date
    - Project info section: project name, job number, address
    - CO description section: title and description as a paragraph
    - Cost breakdown table: columns Description, Cost Type, Qty, Unit, Unit Cost, Amount
    - Cost summary section: subtotals by type (Labor, Materials, Equipment, Subcontractor), Total CO Amount
    - Contract impact section: "Original Contract Sum", "This Change Order Amount", "Revised Contract Sum"
    - Schedule impact: if scheduleImpactDays is not null, show "Schedule Impact: X days"; if null, show "No schedule impact"
    - AIA-format signature block: three blocks — "Owner Signature", "Contractor Signature", "Architect/Engineer Signature" — each with line, Name, Title, Date fields as printed placeholders
    - Brand colors: use BIDAXIOM slate-blue `#3B5BDB` for header accent; status badge colors: Approved=green `#16a34a`, Pending=amber `#d97706`, Rejected=red `#dc2626`
    - Page breaks: `page-break-inside: avoid` on table rows

    **Add `generateChangeOrder` to `apps/api/src/trpc/routers/pdf.ts`:**

    Input schema (zod):
    ```typescript
    z.object({
      projectSlug: z.string(),
      changeOrderId: z.string().uuid(),
    })
    ```

    Procedure implementation:
    1. Look up project by slug. Throw NOT_FOUND if missing.
    2. Look up change order by id with `change_order_line_items` joined. Verify it belongs to this project. Throw NOT_FOUND if missing.
    3. Verify status is "pending" or "approved" (reject with FORBIDDEN if "rejected" or other status).
    4. Get companyProfile (validTo IS NULL) for `documentNamingSettings`. Get company name from `public.tenants`.
    5. Call `getNextDocumentSequence(db, schema, tenantId, "change_order")`.
    6. Call `resolveFileName(documentNamingSettings, "change_order", project.jobNumber, project.name, seq)`.
    7. Compute cost subtotals by `costType` from line items (sum `total` for each type: labor, materials, equipment, subcontractor).
    8. Compute `contractSumAfter` = project.budget + totalCO (or use project's existing contract sum if available). If no budget, show "N/A".
    9. Build `ChangeOrderPdfData` and call `buildChangeOrderHtml(data)`.
    10. Call `generatePdfBuffer(html)`.
    11. Call `uploadPdfAndSave({ ..., category: "change_order", description: `Change Order ${coNumber}: ${co.title}` })`.
    12. Return `{ documentId, fileName, message: "Change Order PDF generated successfully" }`.

    Check `change_order_line_items` schema for field names: look at the `costType` field to know the values used (likely "labor", "materials", "equipment", "subcontractor" — lowercase).
