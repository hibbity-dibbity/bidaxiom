# Phase 38 Plan 03: Proposal PDF Feature End-to-End Summary

**One-liner:** Puppeteer-rendered Proposal PDF with inline-CSS HTML template, pdf.generateProposal tRPC procedure fetching estimate data + uploading to S3, and a "Generate Proposal PDF" button with loading/toast feedback on the estimate detail page.

## What Was Built

End-to-end Proposal PDF generation connecting the estimate UI to the PDF engine infrastructure from 38-02:

1. **`apps/api/src/pdf/templates/proposal.ts`** — `buildProposalHtml(data: ProposalPdfData): string`:
   - All styles inline in a `<style>` block (no external CDN links or stylesheets)
   - Header: company name in 22pt bold, "PROPOSAL" label, date top-right — slate-blue `#3B5BDB` background with white text
   - Project info section: project name, address, estimate name — left-blue-border card style
   - Line items table: Description, Cost Type, Qty, Unit, Unit Cost, Total columns; dark `#1e293b` header; `page-break-inside: avoid` on `tr` elements
   - Subtotals section: Labor, Materials, Equipment, Subcontractor rows; then Overhead and Markup; grand total row in slate-blue background
   - Signature block: two-column layout — "Contractor Signature" and "Owner / Client Signature" — each with signature line, Name, Date, Title printed placeholder fields
   - Footer: "Generated by BIDAXIOM — {date}"
   - `escapeHtml()` applied to all user-supplied strings

2. **`apps/api/src/trpc/routers/pdf.ts`** — `generateProposal` mutation added:
   - Input: `{ projectSlug: string, estimateId: string (uuid) }`
   - Project lookup by slug (NOT_FOUND on missing); estimate lookup with projectId cross-check
   - Line items fetched in orderIndex order
   - Active companyProfile queried for `documentNamingSettings` (validTo IS NULL)
   - Company name from `public.tenants` via raw SQL (cross-schema pattern matching generate.ts)
   - Sequence: `getNextDocumentSequence(db, schema, "proposal")` for atomic increment
   - Filename: `resolveFileName(settings, "proposal", jobNumber, projectName, seq)`
   - Currency formatted with `Intl.NumberFormat("en-US", { style: "currency", currency: "USD" })`
   - Cost type subtotals calculated by aggregating `qty * unitCost` per cost type
   - Calls `buildProposalHtml()` → `generatePdfBuffer()` → `uploadPdfAndSave()`
   - Returns `{ documentId, fileName, message: "Proposal PDF generated successfully" }`

3. **`apps/web/app/(dashboard)/projects/[projectSlug]/estimates/[estimateSlug]/page.tsx`** — UI button:
   - `trpc.pdf.generateProposal.useMutation` with `onSuccess` / `onError` sonner toasts
   - "Generate Proposal PDF" button with `FileText` icon, placed in header next to "Edit Estimate"
   - Button disabled + `Loader2` spinner while `isPending` (PDF generation takes ~2-5s)
   - Success: `toast.success("Proposal PDF generated and saved to document library")`
   - Error: `toast.error(error.message)`
