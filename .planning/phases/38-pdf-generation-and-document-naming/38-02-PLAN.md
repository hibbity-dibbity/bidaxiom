    **Create `apps/api/src/pdf/engine.ts`:**

    Implement Puppeteer singleton browser. Do NOT launch a new browser per request — this causes 500ms+ cold starts:

    ```typescript
    import puppeteer, { type Browser } from "puppeteer";

    let _browser: Browser | null = null;

    export async function getBrowser(): Promise<Browser> {
      if (!_browser || !_browser.connected) {
        _browser = await puppeteer.launch({
          headless: true,
          args: [
            "--no-sandbox",
            "--disable-setuid-sandbox",
            "--disable-dev-shm-usage",
            "--disable-gpu",
          ],
        });
      }
      return _browser;
    }

    export async function generatePdfBuffer(html: string): Promise<Buffer> {
      const browser = await getBrowser();
      const page = await browser.newPage();
      try {
        await page.setContent(html, { waitUntil: "networkidle0" });
        const buffer = await page.pdf({
          format: "Letter",
          printBackground: true,
          margin: { top: "0.75in", right: "0.75in", bottom: "0.75in", left: "0.75in" },
        });
        return Buffer.from(buffer);
      } finally {
        await page.close(); // ALWAYS close in finally — prevents orphaned Chrome tabs
      }
    }
    ```

    **Create `apps/api/src/pdf/generate.ts`:**

    Implements three shared utilities used by all four document-type procedures:

    1. **`getNextDocumentSequence(db, schema, companyId, docType)`** — Atomic counter using Drizzle `.for("update")` pattern (from payment-app.ts:44-81). Uses `db.transaction(async (tx) => { ... })`. Queries `tx.select().from(schema.documentNamingCounters).where(eq(docType)).for("update")`. If no row exists, inserts with `currentNumber: 1` and returns 1. Otherwise increments `currentNumber + 1`, updates the row, returns the new number.

    2. **`resolveFileName(settings, docType, jobNumber, projectName, sequenceNumber)`** — Pure function. Looks up the template from `settings[docType]?.template`. If null/undefined, uses default `"{DOC-TYPE}-{JOB-NUMBER}-{DATE}"`. Replaces variables:
       - `{JOB-NUMBER}` → jobNumber (e.g., "2026-001") or "NOJOB" if null
       - `{PROJECT-NAME}` → slugified project name (replace spaces with dashes, lowercase, max 40 chars)
       - `{DOC-TYPE}` → docType uppercase shorthand ("PROPOSAL", "CO", "PAY-APP", "RFQ")
       - `{SEQ}` → zero-padded sequence number (3 digits, e.g., "003")
       - `{YEAR}` → current 4-digit year
       - `{MONTH}` → zero-padded month ("02")
       - `{DATE}` → YYYY-MM-DD
       Append `.pdf` extension if not present.

    3. **`uploadPdfAndSave(params)`** — Uploads buffer to S3 and inserts into documents + document_versions tables:

    Parameters interface:
    ```typescript
    interface SavePdfParams {
      db: any;             // Drizzle DB instance
      schema: any;         // Tenant schema
      tenantId: string;
      projectId: string;
      userId: string;
      fileName: string;    // From resolveFileName()
      category: string;    // "proposal" | "change_order" | "payment_app" | "rfq"
      description: string;
      pdfBuffer: Buffer;
    }
    ```

    Implementation:
    - Use `getStorageClient()`, `getBucketName()`, `buildStorageKey(tenantId, projectId, fileName)` from `../storage/client.js`
    - Send `PutObjectCommand` with `ContentType: "application/pdf"` and `Body: pdfBuffer`
    - Insert into `schema.documents`: `{ projectId, name: fileName, category, description, fileSize: pdfBuffer.length, contentType: "application/pdf", createdBy: userId }`
    - Insert into `schema.documentVersions`: `{ documentId: doc.id, versionNumber: 1, storageKey: key, fileSize: pdfBuffer.length, contentType: "application/pdf", uploadedBy: userId }`
    - Update `schema.documents` to set `currentVersionId: version.id`
    - Return `{ documentId: doc.id, storageKey: key, fileName }`

    Import `PutObjectCommand` from `@aws-sdk/client-s3`. Import `eq` from `drizzle-orm`.
