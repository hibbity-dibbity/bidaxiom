    **Create `apps/api/src/pdf/templates/proposal.ts`:**

    Export `buildProposalHtml(data: ProposalPdfData): string`.

    ProposalPdfData interface:
    ```typescript
    interface ProposalPdfData {
      companyName: string;
      projectName: string;
      projectAddress: string; // "{street1}, {city}, {state} {zip}" or "Address not provided"
      estimateName: string;
      generatedDate: string;  // ISO date string formatted as "February 19, 2026"
      lineItems: Array<{
        description: string;
        quantity: string;
        unit: string;
        unitCost: string;     // Formatted as "$X,XXX.XX"
        total: string;        // Formatted as "$X,XXX.XX"
        costType: string;     // "Labor" | "Materials" | "Equipment" | "Subcontractor"
      }>;
      subtotalLabor: string;
      subtotalMaterials: string;
      subtotalEquipment: string;
      subtotalSubcontractor: string;
      overheadAmount: string;
      markupAmount: string;
      totalCost: string;
    }
    ```

    HTML template requirements:
    - All styles inline in a `<style>` block — NO external CDN links or stylesheets
    - Header: company name in large text, "PROPOSAL" as document type label, date top-right
    - Project info section: project name, address
    - Line items table with columns: Description, Cost Type, Qty, Unit, Unit Cost, Total
    - Subtotals section by cost type (show Labor, Materials, Equipment, Subcontractor subtotals)
    - Overhead and Markup rows
    - Grand total row (bold, larger font)
    - Signature block section at bottom: two columns — "Contractor Signature" and "Owner/Client Signature" — each with a line, "Name:", "Date:", "Title:" fields as printed placeholders
    - Brand colors: use BIDAXIOM slate-blue `#3B5BDB` as header background/accent (per Phase 28 quick task 28 — slate-blue primary); white text on header
    - Footer: "Generated by BIDAXIOM" with generation date
    - Page breaks: avoid breaking line item rows mid-row (use `page-break-inside: avoid` on tr)

    **Add `generateProposal` to `apps/api/src/trpc/routers/pdf.ts`:**

    Input schema (zod):
    ```typescript
    z.object({
      projectSlug: z.string(),
      estimateId: z.string().uuid(),
    })
    ```

    Procedure implementation:
    1. Look up project by slug (include `jobNumber`, `name`, `street1`, `city`, `state`, `zip`, `id`). Throw TRPCError NOT_FOUND if missing.
    2. Look up estimate by id with line items joined. Throw NOT_FOUND if missing or not belonging to this project.
    3. Look up current active companyProfile (validTo IS NULL) to get `documentNamingSettings`. Also query `public.tenants` for the company name: `SELECT name FROM tenants WHERE id = $tenantId` (access the public schema via the db connection with search_path or direct table reference).
    4. Call `getNextDocumentSequence(db, schema, tenantId, "proposal")`.
    5. Call `resolveFileName(documentNamingSettings, "proposal", project.jobNumber, project.name, seq)`.
    6. Build `ProposalPdfData` from the queried data. Format currency values using `Intl.NumberFormat('en-US', { style: 'currency', currency: 'USD' })`. Format address as `[street1, city, state, zip].filter(Boolean).join(', ')`.
    7. Call `buildProposalHtml(data)` to get the HTML string.
    8. Call `generatePdfBuffer(html)` to get the PDF buffer.
    9. Call `uploadPdfAndSave({ db, schema, tenantId, projectId: project.id, userId, fileName, category: "proposal", description: `Proposal: ${estimate.name}`, pdfBuffer })`.
    10. Return `{ documentId, fileName, message: "Proposal PDF generated successfully" }`.

    Accessing tenants table: The db instance in tRPC context is already scoped to the tenant schema. For the public schema `tenants` table, use the publicSchema tables imported from `../../db/schema/public.js` (or whichever pattern other routers use to access cross-schema data — check how `project.ts` or `organization.ts` accesses public tables).
