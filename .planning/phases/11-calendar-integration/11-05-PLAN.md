**Create `apps/web/components/integrations/calendar-connection-card.tsx`:**

A card component for each calendar provider (Google or Microsoft). Props:
```typescript
interface CalendarConnectionCardProps {
  provider: 'google' | 'microsoft';
  connection?: {
    id: string;
    status: string;
    providerEmail: string | null;
    calendarId: string;
    lastSyncAt: string | null;
    webhookExpiresAt: string | null;
    errorMessage: string | null;
    syncState: {
      syncStatus: string;
      syncedEventCount: number;
      errorCount: number;
      lastFullSyncAt: string | null;
      lastIncrementalSyncAt: string | null;
      lastError: string | null;
    } | null;
  };
}
```

**States:**

1. **Not connected:** Show provider logo/icon and name ("Google Calendar" or "Microsoft Outlook"), status badge "Not Connected" (gray), "Connect" button.
   - Google icon: use lucide Calendar icon with a colored indicator
   - Microsoft icon: use lucide Calendar icon with a different colored indicator
   - Or simply use text labels: "Google Calendar" / "Microsoft Outlook"

2. **Connected:** Status badge "Connected" (green), show:
   - Provider email used for connection
   - Calendar ID (e.g., "primary")
   - Last sync timestamp (relative, using formatDistanceToNow from date-fns)
   - Sync status from syncState (idle/syncing/synced/error)
   - Synced event count
   - "Sync Now" button (triggers incremental sync)
   - "Sync All Projects" button (triggers push-event for all projects)
   - "Disconnect" button with AlertDialog confirmation

3. **Error state:** Status badge "Error" (red), show error message, "Reconnect" button.

4. **Expired state:** Status badge "Expired" (yellow), "Reconnect" button.

**Mutations:**
- Connect: calls `trpc.calendar.getAuthUrl.useMutation()`, redirects to returned URL
- Disconnect: calls `trpc.calendar.disconnect.useMutation()`, invalidates getConnections cache
- Sync Now: calls `trpc.calendar.manualSync.useMutation()`, shows toast
- Sync All Projects: calls `trpc.calendar.syncAllProjects.useMutation()`, shows toast with jobs queued count

Use shadcn/ui Card, Badge, Button, AlertDialog components. Follow the qbo-connection-card styling exactly.

Use Accordion or Collapsible from shadcn/ui for the project list.
