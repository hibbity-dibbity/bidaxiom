**Add to `apps/api/src/db/schema/tenant.ts`** (inside `createTenantSchema`, before the return statement):

1. **`calendarConnections` table:**
   ```
   id: uuid PK defaultRandom
   provider: text NOT NULL                    -- "google" or "microsoft"
   userId: text NOT NULL                      -- Clerk user ID (per-user connections)
   status: text NOT NULL DEFAULT "active"     -- active, disconnected, expired, error
   accessToken: text                          -- Current access token (short-lived, OK unencrypted)
   encryptedRefreshToken: text                -- AES-256-GCM encrypted refresh token
   tokenExpiresAt: timestamptz               -- Access token expiry
   refreshTokenExpiresAt: timestamptz         -- Refresh token expiry (NULL for Google)
   calendarId: text NOT NULL DEFAULT "primary" -- Calendar to sync ("primary" for Google)
   providerEmail: text                        -- Email used during OAuth
   lastSyncAt: timestamptz                    -- Last successful sync
   syncToken: text                            -- Google syncToken or Microsoft deltaLink
   webhookChannelId: text                     -- Google channel ID
   webhookResourceId: text                    -- Google resource ID
   webhookSubscriptionId: text                -- Microsoft subscription ID
   webhookExpiresAt: timestamptz              -- Webhook expiry for renewal scheduling
   errorMessage: text                         -- Last error message
   createdAt: timestamptz DEFAULT NOW NOT NULL
   updatedAt: timestamptz DEFAULT NOW NOT NULL
   ```
   Add unique index on (provider, userId) -- one connection per provider per user.

2. **`calendarEvents` table:**
   ```
   id: uuid PK defaultRandom
   calendarConnectionId: uuid NOT NULL -> calendarConnections.id CASCADE
   projectId: uuid -> projects.id SET NULL   -- NULL for external-origin events
   externalEventId: text NOT NULL            -- Provider event ID
   title: text NOT NULL
   description: text
   startDate: timestamptz NOT NULL
   endDate: timestamptz
   allDay: boolean NOT NULL DEFAULT false
   timezone: text                             -- IANA timezone
   source: text NOT NULL                      -- "platform" or "external"
   sourceEntityType: text                     -- "project" or "project_phase"
   sourceEntityId: text                       -- Project ID or phase ID
   etag: text                                -- Provider ETag for conflict detection
   lastSyncedAt: timestamptz NOT NULL DEFAULT NOW
   createdAt: timestamptz DEFAULT NOW NOT NULL
   updatedAt: timestamptz DEFAULT NOW NOT NULL
   ```
   Add unique index on (calendarConnectionId, externalEventId) -- prevents duplicate events.
   Add index on (projectId) for project milestone queries.
   Add index on (sourceEntityType, sourceEntityId) for reverse lookups.

3. **`calendarSyncState` table:**
   ```
   id: uuid PK defaultRandom
   calendarConnectionId: uuid NOT NULL UNIQUE -> calendarConnections.id CASCADE
   lastFullSyncAt: timestamptz
   lastIncrementalSyncAt: timestamptz
   syncStatus: text NOT NULL DEFAULT "idle"
   syncedEventCount: integer NOT NULL DEFAULT 0
   errorCount: integer NOT NULL DEFAULT 0
   lastError: text
   createdAt: timestamptz DEFAULT NOW NOT NULL
   updatedAt: timestamptz DEFAULT NOW NOT NULL
   ```

Add all three tables to the return statement: `calendarConnections`, `calendarEvents`, `calendarSyncState`.
