**Create `apps/api/src/trpc/routers/calendar.ts`:**

Follow the QuickBooks router pattern (`apps/api/src/trpc/routers/quickbooks.ts`) with these procedures:

1. **`getAuthUrl` (mutation, protected):**
   - Input: `{ provider: 'google' | 'microsoft' }`
   - Validates user has "manage" Calendar permission via CASL
   - Checks for existing active connection for this provider + userId (prevents duplicates)
   - Calls getGoogleCalendarAuthUrl or getMicrosoftCalendarAuthUrl (passing tenantId + userId)
   - Returns `{ url: string }`

2. **`handleCallback` (mutation, protected):**
   - Input: `{ provider: 'google' | 'microsoft', code: string, state: string }`
   - Parses state to validate tenantId matches current context
   - Calls handleGoogleCalendarCallback or handleMicrosoftCalendarCallback
   - Encrypts refresh token using encryptToken()
   - Inserts into calendarConnections table: provider, userId, status: 'active', accessToken, encryptedRefreshToken, tokenExpiresAt, refreshTokenExpiresAt, calendarId ('primary' for Google), providerEmail
   - Creates calendarSyncState row: connectionId, syncStatus: 'idle', syncedEventCount: 0, errorCount: 0
   - Sets up webhook: queues 'renew-webhook' job (which creates initial channel/subscription) OR calls setupGoogleWebhook/setupMicrosoftWebhook directly
   - Queues initial full-sync job: calendarSyncQueue.add('full-sync', { tenantId, provider, connectionId, operation: 'full-sync', syncReason: 'manual' })
   - Audit logs the connection event
   - Returns `{ success: true, connectionId }`

3. **`disconnect` (mutation, protected):**
   - Input: `{ connectionId: string (uuid) }`
   - Validates the connection belongs to current userId
   - Stops webhook channel/subscription (if active): call stopGoogleChannel or cancel Microsoft subscription
   - Updates connection: status = 'disconnected', clears accessToken, encryptedRefreshToken
   - Deletes associated calendarEvents rows
   - Deletes calendarSyncState row
   - Audit logs disconnection
   - Returns `{ success: true }`

4. **`getConnections` (query, protected):**
   - No input (returns all connections for current userId)
   - Queries calendarConnections WHERE userId = ctx.auth.userId
   - For each connection, joins calendarSyncState
   - Returns array of: `{ id, provider, status, providerEmail, calendarId, lastSyncAt, webhookExpiresAt, errorMessage, syncState: { syncStatus, syncedEventCount, errorCount, lastFullSyncAt, lastIncrementalSyncAt, lastError } }`
   - Redacts accessToken and encryptedRefreshToken (never sent to client)
   - If no connections: returns empty array

5. **`getEvents` (query, protected):**
   - Input: `{ connectionId: string (uuid), projectId?: string (uuid) }`
   - Validates connection belongs to current userId
   - Queries calendarEvents WHERE calendarConnectionId = connectionId
   - Optional projectId filter
   - Ordered by startDate ASC
   - Returns array of calendar events (title, startDate, endDate, allDay, source, sourceEntityType)

6. **`syncProject` (mutation, protected):**
   - Input: `{ connectionId: string (uuid), projectId: string (uuid) }`
   - Validates connection belongs to current userId and is active
   - Validates user has read access to the project (CASL check)
   - Queues push-event job: calendarSyncQueue.add('push-event', { tenantId, provider: connection.provider, connectionId, operation: 'push-event', projectId, syncReason: 'manual' })
   - Returns `{ queued: true }`

7. **`syncAllProjects` (mutation, protected):**
   - Input: `{ connectionId: string (uuid) }`
   - Validates connection belongs to current userId and is active
   - Queries all projects the user is a team member of
   - For each project: queues push-event job
   - Returns `{ jobsQueued: number }`

8. **`manualSync` (mutation, protected):**
   - Input: `{ connectionId: string (uuid) }`
   - Validates connection belongs to current userId and is active
   - Queues incremental-sync job
   - Returns `{ queued: true }`

**Permission model:**
- All procedures use protectedProcedure (any authenticated user)
- Per-user enforcement: ALL mutations and queries filter by ctx.auth.userId
- This means each user only manages THEIR OWN calendar connections
- CASL "manage Calendar" permission checked for mutations (connect, disconnect, sync)
- CASL "read Calendar" permission checked for queries (getConnections, getEvents)
- Runtime null checks for tenant/abilities following QBO pattern

**Update `apps/api/src/webhooks/routes.ts`:**

Add these routes inside the existing webhookRoutes function, alongside the Clerk and QBO webhook routes:

1. **`POST /api/webhooks/calendar/google`** -- Google Calendar push notification handler:
   - Extract headers: x-goog-channel-id, x-goog-resource-state, x-goog-channel-token
   - If resourceState === 'sync': return 200 (channel setup confirmation)
   - Call handleGoogleWebhookNotification(headers)
   - If shouldSync: queue incremental-sync job using calendarSyncQueue
   - Return 200 immediately (don't process inline -- webhook endpoint must respond within 10 seconds)

2. **`POST /api/webhooks/calendar/microsoft`** -- Microsoft Graph webhook handler:
   - If request.query.validationToken exists: return 200 with the token as plain text (subscription validation)
   - Parse body for notifications array
   - For each notification: call handleMicrosoftWebhookNotification
   - If shouldSync: queue incremental-sync job
   - Return 202 Accepted (Microsoft expects 202)

3. **`GET /api/integrations/calendar/google/callback`** -- Google OAuth callback:
   - Extract code, scope, state from query params
   - Redirect to frontend: `${CORS_ORIGIN}/settings/integrations/calendar/callback?provider=google&code=${code}&state=${state}`
   - Follows exact QBO callback pattern

4. **`GET /api/integrations/calendar/microsoft/callback`** -- Microsoft OAuth callback:
   - Extract code, state from query params
   - Redirect to frontend: `${CORS_ORIGIN}/settings/integrations/calendar/callback?provider=microsoft&code=${code}&state=${state}`

Import handleGoogleWebhookNotification from google/webhooks.ts and handleMicrosoftWebhookNotification from microsoft/webhooks.ts. Import calendarSyncQueue from shared/queue.ts.
