  <files>apps/api/src/trpc/routers/document.ts</files>
  <action>
Add a new `update` procedure to the documentRouter after the `listUnified` procedure (around line 672). The procedure:

Input schema (inline z.object — no shared schema needed):
```
z.object({
  documentId: z.string().uuid(),
  name: z.string().min(1).max(255).trim(),
  category: z.enum(["rfi", "submittal", "transmittal", "proposal", "change_order", "payment_app", "rfq", "file"]).optional(),
})
```

Logic:
1. Guard: `if (!ctx.tenant || !ctx.userId)` throw INTERNAL_SERVER_ERROR "Tenant context missing"
2. Destructure `const { db, schema } = ctx.tenant`
3. Load abilities via existing `loadProjectAbilities` helper, check `abilities.can("update", "Document")` — throw FORBIDDEN if not
4. Fetch the existing document: SELECT id, projectId, folderId, name FROM documents WHERE id = documentId LIMIT 1 — throw NOT_FOUND if missing
5. Explicit permission check: call existing `loadDocumentPermissions` + `checkDocumentAccess(abilities, explicitPerms, existingDoc, "update")`
6. **Duplicate name check**: The name stored in DB may include the file extension (e.g., "Report.pdf"). Extract the extension from `existingDoc.name` using a helper:
   ```ts
   const lastDot = existingDoc.name.lastIndexOf(".");
   const ext = lastDot > 0 ? existingDoc.name.slice(lastDot) : ""; // e.g., ".pdf"
   const newFullName = ext ? input.name + ext : input.name;
   ```
   Then query: SELECT id FROM documents WHERE projectId = existingDoc.projectId AND ilike(name, newFullName) AND id != documentId LIMIT 1
   If a row is found, throw BAD_REQUEST: "A document with this name already exists in this project"
7. Build update set: `{ name: newFullName, updatedAt: new Date() }` — only add `category` to the set if `input.category !== undefined`
8. Execute `.update(schema.documents).set(updateSet).where(eq(schema.documents.id, input.documentId)).returning()`
9. Return `{ id, name, category }` from the returned row

No audit log needed (keep it simple — pattern established in Phase 55 notes router).
