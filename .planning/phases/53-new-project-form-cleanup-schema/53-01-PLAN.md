**C. Update `apps/api/src/trpc/routers/project.ts`**

In the `create` mutation, in the `tx.insert(schema.projects).values({...})` block (around line 224), add after `projectMode`:

```ts
customerBudget: input.customerBudget != null ? String(input.customerBudget) : null,
buildingWidth: input.buildingWidth != null ? String(input.buildingWidth) : null,
buildingLength: input.buildingLength != null ? String(input.buildingLength) : null,
buildingHeight: input.buildingHeight != null ? String(input.buildingHeight) : null,

```

Drizzle's `numeric` columns accept string values — pass String(number) to preserve precision. `buildingSqft` is auto-calculated server-side: width × length. If either width or length is missing, sqft is stored as null.
