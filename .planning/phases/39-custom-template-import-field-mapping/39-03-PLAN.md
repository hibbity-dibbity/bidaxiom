**Procedures to implement:**

**1. getUploadUrl** — mutation
Input: `{ fileName: string; contentType: "application/vnd.openxmlformats-officedocument.wordprocessingml.document" | "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet"; docType: "proposal" | "change_order" | "payment_app" | "rfq"; name: string }`
Action:
- Validate contentType — only accept the two MIME types above; throw BAD_REQUEST otherwise
- Derive fileType: contentType ends with `wordprocessingml.document` → "docx"; ends with `spreadsheetml.sheet` → "xlsx"
- Use `buildTemplateStorageKey(ctx.tenant!.tenantId, input.fileName)` from storage/client.ts
- Generate presigned PUT URL via `getStorageClient().send(new PutObjectCommand(...))` with ContentType and Expires: 300
- Return: `{ uploadUrl: string; storageKey: string; fileType: "docx" | "xlsx" }`

For presigned URL generation: use the existing S3 presigned pattern — import `getSignedUrl` from `@aws-sdk/s3-request-presigner` and `PutObjectCommand` from `@aws-sdk/client-s3`. Look at `apps/api/src/storage/presigned.ts` for the exact pattern to copy.

**2. registerAndExtract** — mutation
Input: `{ name: string; docType: z.enum([...]); fileType: z.enum(["docx", "xlsx"]); storageKey: string; fileSize: z.number().int().optional() }`
Action:
- Download the file from S3: use `GetObjectCommand` + `getStorageClient()`. Stream to Buffer.
- Extract fields: call `parseDocxFields(buffer)` for docx, `parseXlsxFields(buffer)` for xlsx
- Insert row into `schema.documentTemplates`:
  ```
  { docType, name, fileType, storageKey, fileSize, detectedFields: extractedFields, fieldMappings: extractedFields.map(f => ({ ...f, mappedTo: null })), isActive: false, uploadedBy: ctx.session.userId }
  ```
- Return: `{ templateId: string; detectedFields: ExtractedField[] }`

For streaming S3 object to Buffer: `const chunks: Buffer[] = []; for await (const chunk of body) { chunks.push(Buffer.from(chunk as Uint8Array)); } const buffer = Buffer.concat(chunks);`

**3. updateMappings** — mutation (TMPL-02, TMPL-03 — save always allowed)
Input: `{ templateId: z.string().uuid(); fieldMappings: z.array(z.object({ detectedField: z.string(); displayField: z.string(); mappedTo: z.string().nullable() })) }`
Action:
- Fetch template to verify it belongs to this tenant (security check)
- Compute `unmappedFields = fieldMappings.filter(m => m.mappedTo === null).map(m => m.displayField)`
- Update `field_mappings` + `updated_at` in `schema.documentTemplates`
- Return: `{ savedAt: string; unmappedCount: number; unmappedFields: string[] }`
- Note: save is ALWAYS allowed per CONTEXT.md. Do NOT block on unmapped fields.

**4. generatePreview** — mutation (TMPL-04)
Input: `{ templateId: z.string().uuid() }`
Action:
- Fetch template from `schema.documentTemplates` (verify tenant ownership)
- Fetch company branding via `getCompanyBranding(db, ctx.tenant!.tenantId)` (import from pdf/generate.ts)
- Build preview data: `buildPreviewData({ "company.name": branding.companyName, "company.primaryColor": branding.primaryColor })`
- Build HTML: `buildCustomTemplateHtml(template.fieldMappings, previewData, PREVIEW_LINE_ITEMS, true)` (isPreview=true → unmapped = [UNMAPPED])
- Generate PDF: `const pdfBuffer = await generatePdfBuffer(html)` (import from pdf/engine.ts)
- Upload to S3 with a temporary key `tenants/{tenantId}/previews/{templateId}/preview.pdf` and short Expires (5 minutes)
- Generate a signed GET URL for the preview and return it
- Do NOT insert into `schema.documents` — this is a throw-away preview
- Return: `{ previewUrl: string }` (signed S3 URL valid for 5 minutes)

**5. setActive** — mutation (TMPL-05)
Input: `{ templateId: z.string().uuid(); isActive: boolean }`
Action — MUST be atomic:
```typescript
await db.transaction(async (tx) => {
  // Fetch the template to get its docType
  const [tpl] = await tx.select().from(schema.documentTemplates)
    .where(eq(schema.documentTemplates.id, input.templateId)).limit(1);
  if (!tpl) throw new TRPCError({ code: "NOT_FOUND" });

  if (input.isActive) {
    // Deactivate all templates of this docType first
    await tx.update(schema.documentTemplates)
      .set({ isActive: false, updatedAt: new Date() })
      .where(eq(schema.documentTemplates.docType, tpl.docType));
    // Activate the target
    await tx.update(schema.documentTemplates)
      .set({ isActive: true, updatedAt: new Date() })
      .where(eq(schema.documentTemplates.id, input.templateId));
  } else {
    // Just deactivate this one
    await tx.update(schema.documentTemplates)
      .set({ isActive: false, updatedAt: new Date() })
      .where(eq(schema.documentTemplates.id, input.templateId));
  }
});
```
Per CONTEXT.md: no confirmation dialog, instant toggle, no concurrent-user guard needed (partial unique index enforces at DB level).
