**B. Create apps/api/src/templates/extract.ts**

The file must export two functions: `parseDocxFields(buffer: Buffer): ExtractedField[]` and `parseXlsxFields(buffer: Buffer): Promise<ExtractedField[]>`.

```typescript
// Re-export the shared interface under a local alias for convenience
export interface ExtractedField {
  detectedField: string;  // lowercased key (e.g. "project_name")
  displayField: string;   // as-typed with delimiters (e.g. "<<Project_Name>>")
}
```

**parseDocxFields implementation (from RESEARCH.md Pattern 1):**

1. Load buffer into PizZip
2. Extract `word/document.xml` text and regex-scan for `/<</([^<>]+)>>/gi` to build `originalCaseMap: Map<lowercase, "<<OriginalCase>>">`
3. Create InspectModule: `const InspectModule = require("docxtemplater/js/inspect-module.js");`
4. Create Docxtemplater with:
   - `delimiters: { start: "<<", end: ">>" }`
   - `nullGetter() { return ""; }` — CRITICAL: suppresses undefined tag errors
   - `paragraphLoop: true`, `linebreaks: true`
   - `modules: [iModule]`
5. Call `doc.render({})` inside a try/catch (errors expected for unknown tags, InspectModule still captures all tags)
6. Call `iModule.getAllTags()` — returns `Record<string, unknown>` with lowercased field keys
7. For each key: return `{ detectedField: key, displayField: originalCaseMap.get(key) ?? "<<" + key + ">>" }`

Use CJS require for InspectModule (it does not have a named ESM export): `const InspectModule = require("docxtemplater/js/inspect-module.js");`

**parseXlsxFields implementation (from RESEARCH.md Pattern 2):**

1. Load buffer: `const workbook = new ExcelJS.Workbook(); await workbook.xlsx.load(buffer);`
2. Create `const FIELD_REGEX = /<<([^<>]+)>>/gi;` and `const found = new Map<string, string>();`
3. `workbook.eachSheet(ws => ws.eachRow(row => row.eachCell(cell => { ... })));`
4. For string values: reset `FIELD_REGEX.lastIndex = 0`, exec loop, `found.set(lower, "<<" + original + ">>")` if not already present
5. For RichText values: check `val && typeof val === "object" && "richText" in val`, iterate `richText` array, same regex logic
6. Return `Array.from(found.entries()).map(([key, display]) => ({ detectedField: key, displayField: display }))`

**Note on case preservation:** For both functions, the `displayField` must be the FIRST occurrence of that field name as typed (e.g. if user typed `<<Project_Name>>` and `<<project_name>>`, the first occurrence wins).

**B. apps/api/src/templates/render.ts**

Import `FieldMapping` from `@construction/shared`.

Export `TemplateRenderData = Record<string, string>` type alias.

Export `buildCustomTemplateHtml(mappings: FieldMapping[], data: TemplateRenderData, lineItems?: typeof PREVIEW_LINE_ITEMS): string`.

**Implementation:**

1. Build a lookup map from `detectedField` (lowercase key) → resolved value:
   - If `mappedTo === null` (unmapped): value = `"[UNMAPPED]"` (for preview) or `""` (for production save)
   - If `mappedTo === "IGNORED"`: value = `""`
   - Otherwise: value = `data[mappedTo] ?? "[UNMAPPED]"`
   - Add a second parameter `isPreview: boolean = true` — controls whether unmapped → `[UNMAPPED]` or `""`

2. Separate table-context fields: `mappings.filter(m => m.mappedTo?.startsWith("table."))`

3. Build HTML string. Use a simple, clean layout matching the Phase 38 style (see `apps/api/src/pdf/generate.ts` for styling patterns — white background, company primary color for header, Tailwind-compatible inline styles):
   - Header block: company name (from `data["company.name"]`), company address, phone
   - Scalar field section: a two-column dl/dt/dd list of all non-table mapped fields showing label → value
   - Table section (only if table-context fields exist AND lineItems provided): an HTML `<table>` with `<thead>` from the mapped table field labels, and `<tbody>` rows iterating `lineItems`, mapping each row column via the table field's `mappedTo` key (e.g. `"table.description"` → `row.description`)
   - Footer: "Generated by BIDAXIOM" + generated date

4. All user-supplied data must be HTML-escaped (use a simple escapeHtml helper — replace `&`, `<`, `>`, `"` with entities).

5. Wrap in a complete `<!DOCTYPE html><html>...</html>` structure with inline styles (no external CSS). Font: system-ui, font-size: 14px, color: #111827.
