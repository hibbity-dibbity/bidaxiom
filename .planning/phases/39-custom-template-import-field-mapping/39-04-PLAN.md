**Template card (per template in the list):**
- Template name (bold)
- File type badge: "DOCX" or "XLSX" (muted badge)
- Uploaded date (formatted)
- Field mapping status: "X / Y fields mapped" (read from `fieldMappings.filter(m => m.mappedTo !== null).length` vs `detectedFields.length`)
- Toggle switch (from `components/ui/switch.tsx`) — checked when `isActive`. On toggle:
  - Call `api.template.setActive.useMutation()` with `{ templateId, isActive: !current }`
  - No confirmation dialog per CONTEXT.md (instant toggle)
  - `onSuccess`: invalidate `api.template.listByDocType` query for this docType
  - `onError`: show error toast
- "Map Fields" button → navigates to `/settings/document-templates/${templateId}`
- Delete button (trash icon, destructive variant) → calls `api.template.deleteTemplate.useMutation()` with confirmation using `window.confirm("Delete this template? This cannot be undone.")`

**Upload flow (Upload Template button):**
1. Hidden `<input type="file" accept=".docx,.xlsx">` triggered by button click
2. On file selected:
   a. Show loading state ("Uploading...")
   b. Call `api.template.getUploadUrl.mutateAsync({ fileName, contentType, docType, name: fileName })` to get `{ uploadUrl, storageKey, fileType }`
   c. `fetch(uploadUrl, { method: "PUT", body: file, headers: { "Content-Type": file.type } })`
   d. Call `api.template.registerAndExtract.mutateAsync({ name: fileName, docType, fileType, storageKey, fileSize: file.size })`
   e. `onSuccess`: invalidate listByDocType, show success toast "Template uploaded — map its fields to activate it", then navigate to `/settings/document-templates/${templateId}`
   f. `onError`: show error toast with error message

**Styling:**
