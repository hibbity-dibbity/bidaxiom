Add 7 new tables to `createTenantSchema()` in tenant.ts, following the exact patterns established in Phase 4 (NUMERIC(15,2) for currency, UUID PKs, proper references, timestamps):

**1. sovItems table (Schedule of Values):**
```
id: uuid PK defaultRandom
projectId: uuid NOT NULL references projects(id) ON DELETE CASCADE
budgetLineItemId: uuid references budgetLineItems(id) ON DELETE SET NULL  -- optional link to budget
itemNumber: text NOT NULL  -- e.g., "001", "002" sequential
description: text NOT NULL
scheduledValue: numeric(15,2) NOT NULL  -- dollar amount allocated to this SOV line
orderIndex: integer NOT NULL default 0
createdBy: text NOT NULL
createdAt: timestamp with timezone defaultNow NOT NULL
updatedAt: timestamp with timezone defaultNow NOT NULL
```

**2. paymentApps table (AIA G702 summary):**
```
id: uuid PK defaultRandom
projectId: uuid NOT NULL references projects(id) ON DELETE CASCADE
applicationNumber: text NOT NULL  -- e.g., "PAY-2024-003"
periodStart: timestamp with timezone NOT NULL
periodEnd: timestamp with timezone NOT NULL
originalContractSum: numeric(15,2) NOT NULL
netChangeByChangeOrders: numeric(15,2) default '0'
contractSumToDate: numeric(15,2) NOT NULL
totalCompletedAndStored: numeric(15,2) NOT NULL default '0'
retainageAmount: numeric(15,2) NOT NULL default '0'
totalEarnedLessRetainage: numeric(15,2) NOT NULL default '0'
previousPayments: numeric(15,2) default '0'
currentPaymentDue: numeric(15,2) NOT NULL default '0'
balanceToFinish: numeric(15,2) NOT NULL default '0'
status: text NOT NULL default 'draft'  -- draft, submitted, under_review, approved, rejected, paid
submittedAt: timestamp with timezone
approvedAt: timestamp with timezone
approvedBy: text
paidAt: timestamp with timezone
createdBy: text NOT NULL
createdAt: timestamp with timezone defaultNow NOT NULL
updatedAt: timestamp with timezone defaultNow NOT NULL
```

**3. paymentAppLineItems table (AIA G703 continuation sheet lines):**
```
id: uuid PK defaultRandom
paymentAppId: uuid NOT NULL references paymentApps(id) ON DELETE CASCADE
sovItemId: uuid NOT NULL references sovItems(id) ON DELETE RESTRICT
previousPercentComplete: numeric(5,2) NOT NULL default '0'  -- 0.00 to 100.00
currentPercentComplete: numeric(5,2) NOT NULL  -- 0.00 to 100.00
workCompletedThisPeriod: numeric(15,2) NOT NULL
materialsStoredThisPeriod: numeric(15,2) NOT NULL default '0'
totalCompletedAndStored: numeric(15,2) NOT NULL
retainagePercent: numeric(5,2) NOT NULL
retainageAmount: numeric(15,2) NOT NULL
createdAt: timestamp with timezone defaultNow NOT NULL
```

**4. paymentAppCounters table (sequential numbering):**
```
id: uuid PK defaultRandom
projectId: uuid NOT NULL references projects(id) ON DELETE CASCADE
year: integer NOT NULL
lastNumber: integer NOT NULL default 0
```

**5. retainageHeld table:**
```
id: uuid PK defaultRandom
projectId: uuid NOT NULL references projects(id) ON DELETE CASCADE
paymentAppId: uuid NOT NULL references paymentApps(id) ON DELETE CASCADE
amountHeld: numeric(15,2) NOT NULL
retainageRate: numeric(5,2) NOT NULL  -- snapshot rate at time of payment
status: text NOT NULL default 'held'  -- held, eligible_for_release, released
releasedAmount: numeric(15,2) default '0'
releasedAt: timestamp with timezone
releasedBy: text
releaseNotes: text
createdAt: timestamp with timezone defaultNow NOT NULL
```

**6. lienWaivers table:**
```
id: uuid PK defaultRandom
projectId: uuid NOT NULL references projects(id) ON DELETE CASCADE
paymentAppId: uuid NOT NULL references paymentApps(id) ON DELETE CASCADE
waiverType: text NOT NULL  -- partial_conditional, partial_unconditional, final_conditional, final_unconditional
partyName: text NOT NULL
partyType: text NOT NULL  -- subcontractor, supplier, vendor
throughDate: timestamp with timezone NOT NULL
amountWaived: numeric(15,2) NOT NULL
status: text NOT NULL default 'pending'  -- pending, received, verified, stored
receivedAt: timestamp with timezone
receivedBy: text
requiresNotarization: boolean NOT NULL default false
isNotarized: boolean NOT NULL default false
usesStatutoryForm: boolean NOT NULL default false
documentId: uuid references documents(id) ON DELETE SET NULL
createdAt: timestamp with timezone defaultNow NOT NULL
updatedAt: timestamp with timezone defaultNow NOT NULL
```

**7. paymentAppApprovalSteps table (reuse Phase 5 approval pattern):**
```
id: uuid PK defaultRandom
paymentAppId: uuid NOT NULL references paymentApps(id) ON DELETE CASCADE
stepOrder: integer NOT NULL
approverRole: text
approverUserId: text
requirementType: text NOT NULL default 'all'  -- all, any, specific
status: text NOT NULL default 'pending'  -- pending, approved, rejected, skipped
approvedBy: text
approvedAt: timestamp with timezone
comments: text
```
