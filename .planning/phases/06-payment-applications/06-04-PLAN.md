**Create `sov-editor.tsx`:**
- Props: `{ projectId: string }`
- Query: `trpc.sov.list.useQuery({ projectId })`
- Display SOV items in an editable table:
  - Columns: Item #, Description, Scheduled Value ($), Budget Line Item (linked), Actions
  - Inline editing for description and scheduledValue (click to edit pattern, or use a form dialog)
  - Add item button opens a form dialog: description, scheduledValue, optional budget line item select
  - Delete button (only when no payment apps reference the SOV)
  - Reorder via drag handle or up/down arrows (calls trpc.sov.reorder)
- **Import from Budget** button:
  - Calls `trpc.sov.importFromBudget.useMutation({ projectId })`
  - On success: toast "Imported {N} items from budget", refetch list
  - Only show when SOV is empty or has no submitted payment apps
- Footer: Total Scheduled Value (sum of all items)
- Warning banner if any payment app has been submitted: "SOV is locked. Changes require all payment apps to be in draft status."
- Empty state: "No SOV items yet. Import from budget or add items manually."

**Create `payment-app-list.tsx`:**
- Props: `{ projectId: string }`
- Query: `trpc.paymentApp.list.useQuery({ projectId, status: filterStatus })`
- Summary cards at top (from `trpc.paymentApp.getSummary.useQuery({ projectId })`):
  - Total Approved: $X
  - Total Pending: $X
  - Total Paid: $X
  - Retainage Held: $X (from `trpc.paymentApp.getRetainage.useQuery({ projectId })`)
- Filter dropdown: All, Draft, Submitted, Under Review, Approved, Rejected, Paid
- Table/card layout for each payment app:
  - Application Number (PAY-YYYY-NNN)
  - Period (start - end date formatted)
  - Current Payment Due (formatted USD)
  - Status badge: draft=gray, submitted=yellow, under_review=orange, approved=green, rejected=red, paid=blue
  - Click navigates to detail page
- "New Payment Application" button links to new page
- Prerequisite check: if SOV has 0 items, show warning and link to SOV page instead of new button

**Create `g703-continuation.tsx` (used in both creation and detail views):**
- Props: `{ lineItems: Array<{ sovItemNumber, sovDescription, scheduledValue, previousPercent, currentPercent, workThisPeriod, materialsStored, totalCompleted, retainagePercent, retainageAmount }>, editable?: boolean, onLineItemChange?: (index, field, value) => void }`
- Display as a table matching AIA G703 format:
  - Columns: Item #, Description of Work, Scheduled Value, From Previous App (% and $), This Period (% and $), Materials Stored, Total Completed & Stored, % Complete, Balance to Finish, Retainage
  - If editable: currentPercent is an input field (number, 0-100), materialsStored is an input field
  - Auto-calculate derived values on input change (client-side preview):
    - workThisPeriod = ((currentPercent - previousPercent) / 100) * scheduledValue
    - totalCompleted = (currentPercent / 100) * scheduledValue + materialsStored
    - balanceToFinish = scheduledValue - totalCompleted
  - Footer row: Totals for each numeric column
- Currency formatting: Intl.NumberFormat USD
- Highlight rows where currentPercent < previousPercent (error state, can't go backwards)
