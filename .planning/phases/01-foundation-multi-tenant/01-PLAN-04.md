  <action>
    Install tRPC server packages in apps/api:
    - @trpc/server, @clerk/backend, zod

    apps/api/src/trpc/trpc.ts:
    - Initialize tRPC with initTRPC.context<Context>().create()
    - Export t.router, t.procedure, t.middleware

    apps/api/src/trpc/context.ts:
    - Export type Context and createContext function
    - createContext receives { req: Request }
    - Steps:
      1. Extract Authorization header (Bearer token)
      2. If no token: return { userId: null, tenantId: null, db: null, orgRole: null, hasMfa: false }
      3. Verify Clerk token using @clerk/backend verifyToken() or clerkClient.verifyToken()
      4. Extract userId from verified token
      5. Get active organization from token claims (Clerk's org_id claim)
      6. If no active org: return partial context (userId but no tenant)
      7. Call buildTenantContext(activeOrgId, userId) to get scoped DB and tenant info
      8. Extract orgRole from token claims (Clerk's org_role claim)
      9. Check MFA: read isMfa from session claims (custom claim configured in Clerk)
      10. Return full context: { userId, tenantId, tenantSchema, db (scoped), orgRole, hasMfa, companyName }
    - CRITICAL: Auth verified at THIS layer, not just middleware. This prevents middleware bypass attacks.
    - NEVER store context in globals. Return fresh context per request.

    apps/api/src/trpc/procedures.ts:
    - publicProcedure: t.procedure (no middleware, for health checks)
    - authProcedure: middleware that checks ctx.userId exists, throws UNAUTHORIZED if not
    - protectedProcedure: extends authProcedure, checks:
      1. ctx.hasMfa === true (throw FORBIDDEN "MFA required" if not)
      2. ctx.tenantId exists (throw FORBIDDEN "No active organization" if not)
      3. ctx.db exists (throw INTERNAL_SERVER_ERROR "Tenant DB not available" if not)
    - Export all three procedure types

    apps/api/src/trpc/routers/health.ts:
    - health.check: publicProcedure, returns { status: 'ok', timestamp: new Date().toISOString() }

    apps/api/src/trpc/routers/tenant.ts:
    - tenant.current: protectedProcedure, returns { tenantId: ctx.tenantId, companyName: ctx.companyName, schemaName: ctx.tenantSchema }
    - tenant.list: authProcedure (not protectedProcedure — user may not have active org yet)
      - Query user_company_mappings for ctx.userId
      - Join with tenants table
      - Return list of { tenantId, companyName, schemaName, role }
    - tenant.switch: authProcedure
      - Input: z.object({ orgId: z.string() })
      - Verify user has membership in this org (query user_company_mappings)
      - Return tenant details for the switched org
      - NOTE: Actual org switch happens on Clerk side (OrganizationSwitcher component). This just provides server-side validation.

    apps/api/src/trpc/router.ts:
    - Merge health and tenant routers into appRouter
    - Export appRouter and type AppRouter

    Update apps/api/src/server.ts:
    - Register tRPC as a Fastify route using @trpc/server/adapters/fastify (fastifyTRPCPlugin)
    - Endpoint: /trpc
    - Pass createContext
  </action>

    5. Call tenant.current with valid token + active org → returns tenant info
