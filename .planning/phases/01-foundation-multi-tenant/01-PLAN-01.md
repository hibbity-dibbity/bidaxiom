    - devDependencies: turbo, typescript

    - Pipeline: dev (persistent), build (depends on ^build), lint

    Root tsconfig.json:
    - strict: true, target: ES2022, module: ESNext, moduleResolution: bundler
    - paths: { "@construction/shared": ["packages/shared/src"] }

    .gitignore: node_modules, .next, dist, .env, .env.local, *.tsbuildinfo, .turbo

    .env.example:
    - DATABASE_URL=postgresql://user:pass@localhost:5432/construction_mgmt
    - CLERK_SECRET_KEY=sk_test_xxx
    - CLERK_PUBLISHABLE_KEY=pk_test_xxx
    - NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_test_xxx
    - CLERK_WEBHOOK_SECRET=whsec_xxx
    - REDIS_URL=redis://localhost:6379
    - NEXT_PUBLIC_API_URL=http://localhost:3001

    apps/web (Next.js 14):
    - next@14, react, react-dom
    - tailwindcss, postcss, autoprefixer
    - TypeScript config extends root
    - next.config.mjs: transpilePackages: ["@construction/shared"]
    - tailwind.config.ts: content paths for app/ and components/, extend theme with construction-specific colors if desired
    - app/layout.tsx: basic HTML layout with Tailwind globals import, metadata title "ConstructionSaaS"
    - app/page.tsx: simple placeholder page ("ConstructionSaaS" heading) to verify dev server works
    - app/globals.css: Tailwind directives (@tailwind base/components/utilities)

    apps/api (Fastify):
    - fastify, @fastify/cors, @fastify/helmet
    - tsx for dev running (NOT ts-node — tsx is faster and handles ESM)
    - src/server.ts: Create Fastify instance, register CORS (origin: localhost:3000), register helmet, add GET /health endpoint returning { status: 'ok', timestamp }, listen on port 3001
    - src/env.ts: Validate required env vars exist using Zod (DATABASE_URL, CLERK_SECRET_KEY), export typed config
    - scripts: dev (tsx watch src/server.ts), build (tsc), start (node dist/server.js)

    Initialize shadcn/ui in apps/web:
    - Run: npx shadcn@latest init (accept defaults: New York style, Zinc color, CSS variables: yes)
    - This creates components.json, lib/utils.ts, and sets up the ui component directory

    IMPORTANT: Use npm (not yarn, not pnpm). The monorepo uses npm workspaces.
