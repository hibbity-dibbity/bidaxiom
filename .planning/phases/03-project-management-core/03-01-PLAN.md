Extend `createTenantSchema()` in `apps/api/src/db/schema/tenant.ts` with these 6 new tables:

**projects** table:
- id: uuid PK defaultRandom
- name: text NOT NULL (project name, e.g., "Downtown Office Tower")
- description: text (optional)
- location: text (optional, address or city/state)
- projectType: text NOT NULL (commercial, residential, infrastructure, industrial)
- status: text NOT NULL default 'active' (active, on_hold, completed, archived)
- startDate: timestamp with timezone (optional — may not be set at creation)
- endDate: timestamp with timezone (optional)
- budget: numeric/text for storing decimal budget amounts (optional — set in Phase 4)
- costCodes: jsonb default [] — array of CSI division numbers enabled for this project
- metadata: jsonb default {} — flexible metadata for future extensibility
- createdBy: text NOT NULL (Clerk user ID)
- createdAt: timestamp with timezone defaultNow NOT NULL
- updatedAt: timestamp with timezone defaultNow NOT NULL

**project_team_members** table:
- id: uuid PK defaultRandom
- projectId: uuid NOT NULL references projects(id) onDelete cascade
- userId: text NOT NULL (Clerk user ID)
- role: text NOT NULL (project_manager, superintendent, foreman, estimator, accountant, viewer)
- assignedBy: text NOT NULL (Clerk user ID who assigned)
- assignedAt: timestamp with timezone defaultNow NOT NULL
- Add unique constraint on (projectId, userId) — a user can only have one role per project

**project_phases** table:
- id: uuid PK defaultRandom
- projectId: uuid NOT NULL references projects(id) onDelete cascade
- name: text NOT NULL (e.g., "Pre-Construction", "Foundation", "Framing")
- orderIndex: integer NOT NULL (display order)
- status: text NOT NULL default 'pending' (pending, in_progress, completed)
- startDate: timestamp with timezone (optional)
- endDate: timestamp with timezone (optional)
- createdAt: timestamp with timezone defaultNow NOT NULL

**folders** table:
- id: uuid PK defaultRandom
- projectId: uuid NOT NULL references projects(id) onDelete cascade
- parentId: uuid (self-referential, NULL = root folder). Do NOT add FK constraint to avoid circular reference complexity — use application-level validation
- name: text NOT NULL
- description: text (optional)
- orderIndex: integer NOT NULL default 0
- createdBy: text NOT NULL
- createdAt: timestamp with timezone defaultNow NOT NULL

**documents** table:
- id: uuid PK defaultRandom
- projectId: uuid NOT NULL references projects(id) onDelete cascade
- folderId: uuid references folders(id) onDelete set null (NULL = root level)
- name: text NOT NULL (display name)
- currentVersionId: uuid (points to latest version — updated on each new version upload)
- fileSize: integer (denormalized from current version for list performance)
- contentType: text (denormalized from current version)
- createdBy: text NOT NULL
- createdAt: timestamp with timezone defaultNow NOT NULL
- updatedAt: timestamp with timezone defaultNow NOT NULL

**document_versions** table:
- id: uuid PK defaultRandom
- documentId: uuid NOT NULL references documents(id) onDelete cascade
- versionNumber: integer NOT NULL (1, 2, 3...)
- storageKey: text NOT NULL (S3/MinIO object key)
- fileSize: integer NOT NULL (bytes)
- contentType: text NOT NULL (MIME type)
- uploadedBy: text NOT NULL (Clerk user ID)
- uploadedAt: timestamp with timezone defaultNow NOT NULL
- changeNotes: text (optional version notes)

Add all 6 tables to the return object of `createTenantSchema()`.

Define these Zod schemas and types:

```typescript
import { z } from "zod";

// Project type enum
export const projectTypeEnum = z.enum(["commercial", "residential", "infrastructure", "industrial"]);
export type ProjectType = z.infer<typeof projectTypeEnum>;

// Project status enum
export const projectStatusEnum = z.enum(["active", "on_hold", "completed", "archived"]);
export type ProjectStatus = z.infer<typeof projectStatusEnum>;

// Project team role enum (project-level, distinct from org-level roles)
export const projectRoleEnum = z.enum(["project_manager", "superintendent", "foreman", "estimator", "accountant", "viewer"]);
export type ProjectRole = z.infer<typeof projectRoleEnum>;

// Project phase status
export const phaseStatusEnum = z.enum(["pending", "in_progress", "completed"]);
export type PhaseStatus = z.infer<typeof phaseStatusEnum>;

// Team member assignment
export const teamMemberSchema = z.object({
  userId: z.string().min(1),
  role: projectRoleEnum,
});

// Project phase definition
export const projectPhaseSchema = z.object({
  name: z.string().min(1).max(100),
  orderIndex: z.number().int().min(0),
  startDate: z.string().datetime().optional(),
  endDate: z.string().datetime().optional(),
});

// Create project input
export const createProjectSchema = z.object({
  name: z.string().min(1).max(200),
  description: z.string().max(2000).optional(),
  location: z.string().max(500).optional(),
  projectType: projectTypeEnum,
  startDate: z.string().datetime().optional(),
  endDate: z.string().datetime().optional(),
  costCodes: z.array(z.number().int().min(0).max(49)).default([]),
  teamMembers: z.array(teamMemberSchema).default([]),
  phases: z.array(projectPhaseSchema).default([]),
});

// Update project input
export const updateProjectSchema = z.object({
  id: z.string().uuid(),
  name: z.string().min(1).max(200).optional(),
  description: z.string().max(2000).optional(),
  location: z.string().max(500).optional(),
  projectType: projectTypeEnum.optional(),
  status: projectStatusEnum.optional(),
  startDate: z.string().datetime().nullable().optional(),
  endDate: z.string().datetime().nullable().optional(),
  costCodes: z.array(z.number().int().min(0).max(49)).optional(),
});

// Document creation (after file upload via presigned URL)
export const createDocumentSchema = z.object({
  projectId: z.string().uuid(),
  folderId: z.string().uuid().nullable().optional(),
  name: z.string().min(1).max(255),
  storageKey: z.string().min(1),
  fileSize: z.number().int().positive(),
  contentType: z.string().min(1).max(255),
  changeNotes: z.string().max(500).optional(),
});

// Upload version to existing document
export const uploadVersionSchema = z.object({
  documentId: z.string().uuid(),
  storageKey: z.string().min(1),
  fileSize: z.number().int().positive(),
  contentType: z.string().min(1).max(255),
  changeNotes: z.string().max(500).optional(),
});

// Folder creation
export const createFolderSchema = z.object({
  projectId: z.string().uuid(),
  parentId: z.string().uuid().nullable().optional(),
  name: z.string().min(1).max(100),
  description: z.string().max(500).optional(),
});

// Presigned URL request
export const presignedUrlSchema = z.object({
  projectId: z.string().uuid(),
  fileName: z.string().min(1).max(255),
  contentType: z.string().min(1).max(255),
  fileSize: z.number().int().positive().max(524288000), // 500MB max
});

// Default construction folder templates
export const DEFAULT_PROJECT_FOLDERS = [
  { name: "Contracts", order: 1, description: "Owner contracts, subcontracts, purchase orders" },
  { name: "Drawings", order: 2, description: "Architectural, structural, MEP drawings" },
  { name: "Specifications", order: 3, description: "Project specifications organized by CSI division" },
  { name: "Submittals", order: 4, description: "Material and equipment submittals" },
  { name: "RFIs", order: 5, description: "Requests for Information" },
  { name: "Change Orders", order: 6, description: "Owner and subcontractor change orders" },
  { name: "Payment Applications", order: 7, description: "AIA G702/G703 forms, lien waivers" },
  { name: "Invoices", order: 8, description: "AP/AR documentation" },
  { name: "Reports", order: 9, description: "Daily reports, inspection reports, progress photos" },
  { name: "Closeout", order: 10, description: "As-builts, warranties, O&M manuals" },
] as const;

// Default project phases
export const DEFAULT_PROJECT_PHASES = [
  { name: "Pre-Construction", orderIndex: 0 },
  { name: "Mobilization", orderIndex: 1 },
  { name: "Foundation", orderIndex: 2 },
  { name: "Structural", orderIndex: 3 },
  { name: "Rough-In", orderIndex: 4 },
  { name: "Finishes", orderIndex: 5 },
  { name: "Closeout", orderIndex: 6 },
] as const;
```
