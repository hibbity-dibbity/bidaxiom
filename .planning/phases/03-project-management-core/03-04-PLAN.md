  <name>Task 1: Create document tRPC router with upload, versioning, and folder management</name>
  <files>
    apps/api/src/trpc/routers/document.ts
  </files>
  <action>
Create `apps/api/src/trpc/routers/document.ts` with these procedures. Follow the same patterns established in the project router (Plan 03) for loading project abilities and performing CASL checks.

**Import from @construction/shared:** createDocumentSchema, uploadVersionSchema, createFolderSchema, presignedUrlSchema
**Import from storage:** generateUploadUrl, generateDownloadUrl
**Import from audit:** createAuditLog

**Helper:** Reuse or adapt the same `loadProjectAbilities` helper from the project router to check project team membership for Document and Folder subjects.

**Procedures:**

1. **document.getUploadUrl** (protectedProcedure, input: presignedUrlSchema)
   - Check CASL: user must be able to "create" a "Document" on this project (`throwUnlessCan("create", "Document", { projectId: input.projectId })`)
   - Validate file size (max 500MB = 524288000 bytes) — already validated by Zod schema but add runtime check too
   - Call `generateUploadUrl(ctx.tenant.tenantId, input.projectId, input.fileName, input.contentType)`
   - Return `{ uploadUrl, storageKey }` — the client uses uploadUrl to PUT the file, then calls document.create with storageKey

2. **document.create** (protectedProcedure, input: createDocumentSchema)
   - Check CASL: `throwUnlessCan("create", "Document", { projectId: input.projectId })`
   - Validate that the project exists and belongs to this tenant
   - If folderId provided, validate folder exists and belongs to same project
   - In a transaction:
     a. Insert into `documents` table: name, projectId, folderId, fileSize, contentType, createdBy
     b. Insert into `document_versions` table: documentId, versionNumber=1, storageKey, fileSize, contentType, uploadedBy, changeNotes
     c. Update documents.currentVersionId to point to the new version
   - Audit log: entityType "Document", action "create", entityId = document.id
   - Return the created document with its first version

3. **document.uploadVersion** (protectedProcedure, input: uploadVersionSchema)
   - Fetch the existing document to get its projectId
   - Check CASL: `throwUnlessCan("update", "Document", { projectId: doc.projectId })`
   - Get the current highest version number for this document
   - In a transaction:
     a. Insert new version into `document_versions`: versionNumber = max + 1, storageKey, fileSize, contentType, uploadedBy, changeNotes
     b. Update `documents` table: set currentVersionId to new version id, update fileSize and contentType (denormalized), set updatedAt
   - Audit log: entityType "Document", action "upload_version", changes include version number
   - Return the new version record

4. **document.list** (protectedProcedure, input: z.object({ projectId: z.string().uuid(), folderId: z.string().uuid().nullable().optional() }))
   - Check CASL: `throwUnlessCan("read", "Document", { projectId: input.projectId })`
   - Query documents WHERE projectId = input.projectId AND folderId = input.folderId (NULL = root level)
   - Order by name asc
   - Return documents with current version metadata (fileSize, contentType, uploadedAt from denormalized fields)

5. **document.getDownloadUrl** (protectedProcedure, input: z.object({ documentId: z.string().uuid() }))
   - Fetch document and its current version to get storageKey
   - Check CASL: `throwUnlessCan("read", "Document", { projectId: doc.projectId })`
   - Call `generateDownloadUrl(currentVersion.storageKey, doc.name)`
   - Return `{ downloadUrl, fileName: doc.name, contentType, fileSize }`

6. **document.getVersionHistory** (protectedProcedure, input: z.object({ documentId: z.string().uuid() }))
   - Fetch document to get projectId
   - Check CASL: `throwUnlessCan("read", "Document", { projectId: doc.projectId })`
   - Query document_versions WHERE documentId, ordered by versionNumber desc
   - Return array of versions with metadata

7. **document.delete** (protectedProcedure, input: z.object({ documentId: z.string().uuid() }))
   - Fetch document to get projectId
   - Check CASL: `throwUnlessCan("delete", "Document", { projectId: doc.projectId })`
   - Delete from documents (cascades to document_versions via FK)
   - Note: Does NOT delete the actual S3 objects — orphaned storage cleanup is a future concern (S3 lifecycle policies)
   - Audit log: entityType "Document", action "delete"
   - Return { success: true }

8. **document.createFolder** (protectedProcedure, input: createFolderSchema)
   - Check CASL: `throwUnlessCan("create", "Folder", { projectId: input.projectId })`
   - If parentId provided, validate it exists and belongs to same project
   - Get max orderIndex for this parent to set new folder's orderIndex
   - Insert into folders table
   - Audit log: entityType "Folder", action "create"
   - Return the created folder

9. **document.listFolders** (protectedProcedure, input: z.object({ projectId: z.string().uuid(), parentId: z.string().uuid().nullable().optional() }))
   - Check CASL: `throwUnlessCan("read", "Folder", { projectId: input.projectId })`
   - Query folders WHERE projectId AND parentId match (NULL = root folders)
   - Order by orderIndex asc
   - Return array of folders

10. **document.renameFolder** (protectedProcedure, input: z.object({ folderId: z.string().uuid(), name: z.string().min(1).max(100) }))
    - Fetch folder to get projectId
    - Check CASL: `throwUnlessCan("update", "Folder", { projectId: folder.projectId })`
    - Update folder name
    - Audit log: entityType "Folder", action "rename"
    - Return updated folder

**Important notes:**
- Every procedure must check CASL permissions with project-level conditions
- Every mutation must write an audit log entry using createAuditLog (fire-and-forget)
- File validation: the Zod schemas handle input validation (max sizes, required fields). The router trusts that the client uploaded via the pre-signed URL before calling document.create.
- Storage key validation: verify the storageKey starts with `tenants/${ctx.tenant.tenantId}/` to prevent cross-tenant key injection
