**Create `apps/web/app/(dashboard)/projects/[projectId]/page.tsx`** — Project dashboard:
- Use `"use client"` directive
- Get projectId from route params (Next.js 15 App Router: `params` is a Promise, so use `use(params)` or `await params`)
- Call `trpc.project.getById.useQuery({ id: projectId })` to fetch project details
- Layout sections:
  1. **Header**: Project name, status badge, edit button. Breadcrumb: Projects > Project Name
  2. **Overview cards** (grid, 2-4 cols):
     - Budget: placeholder showing "$0 / TBD" (actual budget management comes in Phase 4)
     - Schedule: start date - end date range, or "Not set"
     - Team: member count with link to expand
     - Status: current project status with ability to change (dropdown)
  3. **Team section**: Table/list of team members showing name/email, project role, assigned date. Add member button (opens dialog with user ID input + role select, calls trpc.project.addTeamMember). Remove button per member (calls trpc.project.removeTeamMember with confirmation dialog).
  4. **Phases section**: List of project phases with status indicators (pending = gray, in_progress = blue, completed = green). Simple display only (editing handled via updatePhases).
  5. **Documents quick link**: Card linking to `/projects/[projectId]/documents` with document count if available
  6. **Recent Activity**: Call `trpc.audit.entityHistory` or `trpc.audit.list` with entityType "Project" and entityId = projectId. Show last 10 audit entries (who did what, when). If audit router doesn't support this filter, show a placeholder "Activity feed coming soon."
- Use shadcn/ui: Card, Badge, Button, Table, Dialog, Avatar (for team members), Separator

**Create `apps/web/components/project/folder-tree.tsx`** — Folder tree navigation:
- Use `"use client"` directive
- Props: `projectId: string`, `selectedFolderId: string | null`, `onFolderSelect: (folderId: string | null) => void`
- Call `trpc.document.listFolders.useQuery({ projectId, parentId: null })` for root folders
- Render as a vertical list of folder items with folder icon, name, and click handler
- Selected folder has highlighted background
- "All Documents" option at top (folderId = null) to show root-level documents
- "New Folder" button at bottom that opens a dialog with name input, calls `trpc.document.createFolder`
- For v1, implement flat folder display only (root level). Nested folder expansion can be added later if needed.
- Use shadcn/ui: Button, Dialog, Input

**Create `apps/web/components/project/document-uploader.tsx`** — Document upload component:
- Use `"use client"` directive
- Props: `projectId: string`, `folderId: string | null`, `onUploadComplete: () => void`
- Implements a two-step upload flow:
  1. User selects file(s) via file input or drag-and-drop zone
  2. For each file:
     a. Call `trpc.document.getUploadUrl.mutate({ projectId, fileName, contentType, fileSize })`
     b. PUT file to the returned uploadUrl using fetch()
     c. Call `trpc.document.create.mutate({ projectId, folderId, name, storageKey, fileSize, contentType })`
- Show upload progress (use state to track each file: pending, uploading, registering, complete, error)
- Drag-and-drop zone: dashed border area with "Drop files here or click to browse" text
- File type display: show file icon, name, size
- Multiple file upload support (process sequentially to avoid overwhelming S3)
- Max file size: 500MB (validate client-side before requesting pre-signed URL)
- On complete, call `onUploadComplete()` to trigger document list refetch
- Use shadcn/ui: Button, Progress, Dialog

**Create `apps/web/app/(dashboard)/projects/[projectId]/documents/page.tsx`** — Document browser:
- Use `"use client"` directive
- Get projectId from route params
- State: `selectedFolderId: string | null` (null = root level)
- Layout:
  1. **Header**: "Documents" with breadcrumb (Projects > Project Name > Documents). Upload button opens DocumentUploader dialog.
  2. **Two-column layout** (sidebar + main):
     - Left sidebar (w-64): FolderTree component
     - Main content: Document list for selected folder
  3. **Document list**: Call `trpc.document.list.useQuery({ projectId, folderId: selectedFolderId })`
     - Display as a table: File name (with file type icon), Size (human-readable), Uploaded by, Date, Actions
     - Actions column: Download button (calls trpc.document.getDownloadUrl, opens URL in new tab), Version history button (expands to show versions below the row or in a sheet/dialog)
     - Version history: Shows list of versions with version number, uploaded by, date, change notes, download link per version
     - Loading state: skeleton table rows
     - Empty state: "No documents in this folder. Upload your first document."
  4. **Upload dialog**: DocumentUploader component in a Dialog, triggered by Upload button
- On mobile: hide sidebar, show folder selector as a dropdown above the document list
- Use shadcn/ui: Table, Button, Dialog, DropdownMenu, Badge, Sheet (for version history)

**Important implementation notes:**
- For file size display, create a simple `formatFileSize(bytes: number): string` helper (e.g., "2.5 MB")
- For date display, format dates nicely (e.g., "Feb 12, 2026"). Use Intl.DateTimeFormat or date-fns if already installed.
- All tRPC queries should use proper loading/error states
- Use Next.js Link for navigation between pages
- For team member display, use clerk_user_id as identifier. The project.getById response should include team member details (name, email from user_profiles table).
