Create centralized schemas for each entity in packages/shared/src/schemas/:

**Pattern for each schema file:**
```typescript
import { z } from "zod";
import { addressSchema, phoneSchema } from "./common";

// Create schema (used by client forms and server create mutations)
export const create[Entity]Schema = z.object({
  field1: z.string().min(1, "Field1 is required"),
  field2: z.string().optional(),
  // Include ALL fields needed for creation
});

// Update schema (used by client edit forms and server update mutations)
export const update[Entity]Schema = create[Entity]Schema.partial();

// Filter schema (used by list pages with nuqs and server list queries)
export const [entity]FilterSchema = z.object({
  search: z.string().optional(),
  status: z.enum(["active", "inactive"]).optional(),
  // URL-safe filters for list pages
});

// Type inference
export type Create[Entity]Input = z.infer<typeof create[Entity]Schema>;
export type Update[Entity]Input = z.infer<typeof update[Entity]Schema>;
export type [Entity]Filter = z.infer<typeof [entity]FilterSchema>;
```

Example for project router:
```typescript
import { createProjectSchema, updateProjectSchema } from "@construction/shared";

export const projectRouter = router({
  create: protectedProcedure
    .input(createProjectSchema)  // Was: .input(z.object({...}))
    .mutation(async ({ ctx, input }) => {
      // input is now CreateProjectInput type
    }),
  update: protectedProcedure
    .input(z.object({ id: z.string().uuid(), data: updateProjectSchema }))
    .mutation(async ({ ctx, input }) => {
      // ...
    }),
});
```

**Client migration (React Hook Form components):**

For each form component:
1. Remove local schema definition (const formSchema = z.object({...}))
2. Import from shared: `import { createProjectSchema } from "@construction/shared";`
3. Update useForm: `resolver: zodResolver(createProjectSchema)`
4. Update type inference: `type FormValues = z.infer<typeof createProjectSchema>;`

}
