## Milestone Summary

**Key Decisions:**

- `getSafeRedirectUrl` validates relative URLs (must start with `/`, not `//` or `/\`) — open-redirect guard
- `window.location.href` for session expiry redirects (full page reload ensures middleware re-evaluates iron-session cookie; `router.push` would leave broken session)
- `SessionWatcher` as a tiny client component in dashboard layout (layout stays a Server Component)
- `globalThis.fetch` in tRPC interceptor prevents infinite recursion
- `changePassword` revokes refresh tokens; `disableMfa` does NOT (credential rotation vs settings change)
- `ctx.userId` pattern for auth mutations (createContext already verifies JWT; no manual Bearer extraction needed in tRPC)
- tRPC REST handler: raw input body, no `{ json: {} }` wrapper (no superjson transformer)
- `collapsible="icon"` for sidebar (icon-only collapse mode, not `"none"` which disables toggle entirely)
- `generateNameSlug` (no UUID prefix) for customers/subs; projects keep UUID-prefixed `generateProjectSlug`
- `router.replace` for post-rename slug navigation (old slug not left in browser history)
- Estimates `CommandGroup` `.some()` guard avoids empty heading in command palette
- `QueryCache.onError` (not `defaultOptions.queries.onError`) — correct v5 react-query API
- `startingSequenceNumber` floors `nextSequenceNumber` at `maxUsed+1` — prevents duplicate job numbers
- Uniqueness check inside `db.transaction` — eliminates load-compare-write race window

**Issues Resolved:**
- Frontend slug routing incomplete for customers and subcontractors (completed in Phase 27)
- Session expiry silently broken — users had to refresh to discover expired session (fixed Phase 25)
- Account settings fragmented across multiple pages/dropdown links (consolidated Phase 26)
- Global search missing estimates (fixed Phase 28)
- Dashboard KPI widgets non-navigable (fixed Phase 28)
- Job number counter not advancing on manual edit-page save (fixed Phase 29)
- UUID prefix in customer/sub slug generation producing ugly URLs (hotfixed during Phase 27 UAT)
- Triple toast on API block (deduplication via toast id — Phase 29 UAT)
- nextSequenceNumber stale after project save (cache invalidation — Phase 29 UAT)

**Technical Debt Incurred:**
- Phase 27 VERIFICATION.md was never generated (UAT summary serves as substitute evidence)
- Sign-in page passes `redirect_url` unvalidated at page level; `getSafeRedirectUrl` only fires at `router.push` time (defense-in-depth gap, no current exposure)
- MFA `hasMfa` state refresh lag after `disableMfa` — shows stale "Enabled" until re-login
