Interface (TypeScript):
```typescript
interface SendToCustomerDialogProps {
  open: boolean;
  onOpenChange: (open: boolean) => void;
  documentName: string;
  prePopulatedEmail: string | null | undefined;
  prePopulatedSubject?: string;
  isPending: boolean;
  onSend: (data: { recipients: string[]; subject: string; note: string }) => void;
}
```

Internal state: `recipientInput` (string), `subject` (string), `note` (string) — all initialized to `""`.

Pre-population behavior: use a single `useEffect` that fires when `open` becomes true. Inside it:
- If `prePopulatedEmail` is set and `recipientInput` is currently empty, set `recipientInput` to `prePopulatedEmail`.
- If `prePopulatedSubject` is set and `subject` is currently empty, set `subject` to `prePopulatedSubject`.
This prevents overwriting user edits if the dialog is closed and reopened.

Reset behavior: use a second `useEffect` that fires when `open` becomes false — reset all three fields to `""` so the dialog starts clean on next open.

`handleSend`:
```typescript
const handleSend = () => {
  const recipients = recipientInput
    .split(",")
    .map((e) => e.trim())
    .filter(Boolean);
  onSend({ recipients, subject, note });
};
```
