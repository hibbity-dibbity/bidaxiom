# Plan 47-01: Remove Unwanted Sidebar Nav Entries and Navigation Heading

## Goal

When this plan is complete, the sidebar shows only Dashboard, Projects, Customers, Subcontractors, and Settings — with no "Navigation" group heading — and the codebase has no orphaned icon imports or unused JSX components.

## Context

Two files need surgical edits:

- `apps/web/components/layout/sidebar-nav.tsx` — holds the flat `mainNav` array. Four entries (Bidding, Financials, Documents, Reports) at lines 27–30 are deleted. Four Lucide icon imports that become unused (`Briefcase`, `DollarSign`, `FileText`, `BarChart`) are also removed from the import block at lines 6–15.
- `apps/web/components/layout/sidebar.tsx` — holds the `<SidebarGroupLabel>Navigation</SidebarGroupLabel>` JSX at line 85. That line is deleted, and the now-unused `SidebarGroupLabel` named import at line 10 is removed.

No other files are affected. There are no tests, no role guards, no dynamic data — this is a pure static config edit. The `<SidebarGroup>` wrapper remains; only its label child is removed. The `/reports` route pages still exist on disk after this change (intentional).

## Tasks

### Task 1: Remove four nav entries and their orphaned icon imports from sidebar-nav.tsx

**File**: `apps/web/components/layout/sidebar-nav.tsx`

**Action**: Delete the four `mainNav` array entries for Bidding, Financials, Documents, and Reports, then remove the four now-unused Lucide icon imports from the import block.

**Details**:

- Delete these four lines from the `mainNav` array:
  ```typescript
  { href: "/bids",       label: "Bidding",    icon: Briefcase },
  { href: "/financials", label: "Financials", icon: DollarSign },
  { href: "/documents",  label: "Documents",  icon: FileText },
  { href: "/reports",    label: "Reports",    icon: BarChart },
  ```
- Remove `DollarSign`, `FileText`, `BarChart`, and `Briefcase` from the `lucide-react` import. The remaining imports are: `Home`, `FolderKanban`, `Users`, `HardHat`, `Settings`.
- Do not touch any other lines. The five remaining `mainNav` entries (Dashboard, Projects, Customers, Subcontractors, Settings) are unchanged.

**File**: `apps/web/components/layout/sidebar.tsx`
