# Plan 49-03: Remove Change Orders phase gate

## Context

**Gap:** Change Orders tab is missing on pre-award projects (lifecycle phases: opportunity, estimating, submitted) because `ALL_SECTIONS` in `project-tabs.tsx` has `phaseGated: "change_orders"` which only allows the tab after award.

**Why fix:** In the simplified UX (no project modes), Change Orders should always be visible in the tab bar. The phase gate was a holdover from the GC/Advanced design — showing an empty or soon-to-be-relevant tab is acceptable and consistent with the Expenses placeholder pattern.

**Note:** Do NOT remove `PHASE_FEATURE_GATES["change_orders"]` from `packages/shared` — that gate may still be used server-side as a mutation guard. Only remove the tab visibility gate.

## Tasks

### Task 1: Remove phaseGated from Change Orders entry in project-tabs.tsx

**File:** `apps/web/app/(dashboard)/projects/[projectSlug]/components/project-tabs.tsx`

**Change:** Remove `phaseGated: "change_orders"` property from the Change Orders entry in `ALL_SECTIONS`.

**Before:**
```ts
{ name: "Change Orders", href: "/change-orders", phaseGated: "change_orders" },
```

**After:**
```ts
{ name: "Change Orders", href: "/change-orders" },
```

**Verify:** After the change, grep for `phaseGated` in project-tabs.tsx — should return zero results (since no other entry has phaseGated).

**Commit:** `fix(49-03): remove Change Orders phase gate — tab visible on all projects`

## Acceptance Criteria

- Change Orders tab appears on all projects regardless of lifecycle phase
- Five other tabs (Overview, Documents, Proposals, Invoices, Expenses) are unaffected
- `PHASE_FEATURE_GATES` in `packages/shared/src/types/project.ts` is NOT modified
