**Step 2 — Fix `MyActiveProjects` onClick:**

`MyActiveProjects` currently has `onClick={() => router.push("/projects")}` — it navigates but omits the user filter. Replace this with:

```typescript
export function MyActiveProjects() {
  const router = useRouter();
  const { userId } = useAuth();
  // ... existing data fetching ...
  return (
    <KpiCard
      // ... existing props ...
      onClick={() => {
        const params = new URLSearchParams({ status: "active" });
        if (userId) params.set("assignedUser", userId);
        router.push(`/projects?${params.toString()}`);
      }}
    />
  );
}
```

The `userId` from `useAuth()` is the user's UUID string (e.g., `"usr_abc123"`). The projects page reads `assignedUser` via nuqs `parseAsString` and passes it as `assignedUserId` to the tRPC query. Passing the raw UUID is correct — do NOT use a sentinel like `"me"`.

**Step 3 — Add onClick to `MyOpenBids`:**
