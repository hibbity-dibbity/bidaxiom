<task type="auto">
  <name>Task 2: Set BIDAXIOM icon as favicon via file-based detection and metadata API</name>
  <files>
    apps/web/app/icon.png (CREATE — binary copy of apps/web/public/bidaxiom-icon.png)
    apps/web/app/layout.tsx (MODIFY — add icons field to metadata)
  </files>
  <action>
    STEP A — Create apps/web/app/icon.png via file copy:

    Run:
      cp "apps/web/public/bidaxiom-icon.png" "apps/web/app/icon.png"

    This is Next.js App Router file-based favicon auto-detection. Next.js serves any file named
    icon.png placed directly in the app/ directory as a favicon automatically. The file must be in
    app/ (not public/) for this mechanism to work.

    Verify the file exists:
      ls -la apps/web/app/icon.png
    Expected: file exists, size matches apps/web/public/bidaxiom-icon.png

    STEP B — Add icons field to metadata in apps/web/app/layout.tsx:

    Read the file first. Then update the metadata export to add the icons field.

    BEFORE:
      export const metadata: Metadata = {
        title: {
          template: "%s | BIDAXIOM",
          default: "BIDAXIOM",
        },
        description: "Construction management software for general contractors and subcontractors",
      };

    AFTER:
      export const metadata: Metadata = {
        title: {
          template: "%s | BIDAXIOM",
          default: "BIDAXIOM",
        },
        description: "Construction management software for general contractors and subcontractors",
        icons: {
          icon: '/bidaxiom-icon.png',
          shortcut: '/bidaxiom-icon.png',
          apple: '/bidaxiom-icon.png',
        },
      };

    The icons field references /bidaxiom-icon.png which is served from public/ at runtime.
    This is belt-and-suspenders: file-based (app/icon.png) handles most browsers;
    metadata.icons handles PWA, bookmarks, and edge cases.

    Do NOT modify any other part of layout.tsx.

    Then commit both files:
      git add apps/web/app/icon.png apps/web/app/layout.tsx
      git commit -m "feat(31-02): add BIDAXIOM favicon via file-based detection and metadata API"
  </action>
  <verify>

    Expected: file exists with same size as apps/web/public/bidaxiom-icon.png

    grep -A 5 'icons:' apps/web/app/layout.tsx
    Expected: icons block present with icon, shortcut, and apple entries

    git diff HEAD~1 apps/web/app/layout.tsx
    Expected: only the icons field added to metadata; nothing else changed
  </verify>
  <done>
