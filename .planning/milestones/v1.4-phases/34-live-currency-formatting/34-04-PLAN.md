The approach here: let CurrencyInput's `onChange` update `amountValue`, then `onBlur` calls `handleAmountBlur(amountValue)`. However, since onChange fires before onBlur in CurrencyInput's handleBlur, and React state updates are batched, we need to pass the value from CurrencyInput's onChange directly. This works because CurrencyInput calls `onChange(numericValue)` only on blur (not on every keystroke). Remove the separate `handleAmountBlur` function or simplify it to just the state reset.
