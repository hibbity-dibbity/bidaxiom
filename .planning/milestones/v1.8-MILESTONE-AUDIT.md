## Tech Debt

### 1. Building Dimensions Not Updatable (Phase 53)

**Severity:** Medium — functional gap, no stated requirement violated
**File:** `apps/api/src/trpc/routers/project.ts`, lines 655-681
**Issue:** The `project.update` mutation handler's `updateValues` builder is missing write blocks for `buildingWidth`, `buildingLength`, `buildingHeight`, and `buildingSqft` recomputation. The `updateProjectSchema` accepts these fields; the API silently discards them.
**Impact:** Dimensions set at project creation are preserved in the DB and display correctly on Overview. However, if a user opens the project edit page and changes dimensions, the update is silently dropped.
**Fix (4 lines in project.ts):**
```ts
if (input.buildingWidth !== undefined)
  updateValues.buildingWidth = input.buildingWidth !== null ? String(input.buildingWidth) : null;
if (input.buildingLength !== undefined)
  updateValues.buildingLength = input.buildingLength !== null ? String(input.buildingLength) : null;
if (input.buildingHeight !== undefined)
  updateValues.buildingHeight = input.buildingHeight !== null ? String(input.buildingHeight) : null;
// Recompute sqft when width or length changes
if (input.buildingWidth !== undefined || input.buildingLength !== undefined) {
  const w = input.buildingWidth ?? existingProject?.buildingWidth;
  const l = input.buildingLength ?? existingProject?.buildingLength;
  updateValues.buildingSqft = (w != null && l != null) ? String(Number(w) * Number(l)) : null;
}
```
