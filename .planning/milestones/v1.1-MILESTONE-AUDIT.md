### ❌ Broken Integrations (2)

#### Break #1: Search Returns UUID URLs
**Location:** `apps/api/src/trpc/routers/search.ts:60`

**Issue:**
```typescript
url: `/projects/${p.id}`,  // ❌ Returns UUID
```

**Expected:**
```typescript
url: `/projects/${generateSlug(p.jobNumber, p.name)}`,  // ✓ Should return slug
```

**Impact:**
- Users press ⌘K and search for project
- Click result, navigate to `/projects/{uuid}`
- Route doesn't exist (only `/projects/{slug}` exists)
- User sees 404 error
- **Breaks E2E Flow #2**

**Severity:** CRITICAL - Breaks global search navigation

---

#### Break #2: Convert to Project Uses UUID Navigation
**Location:** `apps/web/components/estimates/actions/ConvertToProjectButton.tsx:29`

**Issue:**
```typescript
router.push(`/projects/${projectId}/budget`);  // ❌ Uses UUID
```

**Expected:**
```typescript
router.push(`/projects/${projectSlug}/budget`);  // ✓ Should use slug
```

**Impact:**
- User converts estimate to project
- Redirect navigates to `/projects/{uuid}/budget`
- Route doesn't exist, user sees 404
